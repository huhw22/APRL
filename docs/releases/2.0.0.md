# APRL 2.0 固定记录

2026-11-17 固定为 **2.0.0**，Git 标签 **`v2.0.0`**。后续开发使用新提交和新版本号；
不移动此标签，不覆盖已冻结的输入、结果和交付包。

首选算法为 **能量守恒耦合＋纵向三点核抑制**：

```yaml
mesh:
  field_solver: cowan-z
  particle_coupling: conservative-source
  longitudinal_shape: linear-binomial3
  current_filter: none
  self_field_feedback: true
```

[推荐片段](../../config/profiles/v2.0-three-point.yaml)需复制到完整工况卡的 mesh 中，
不是独立可运行输入，程序也不自动合并片段。[完整示例](../../config/example.yaml)已显式采用这组设置。
三点核不是额外的 `current_filter: compensated-bilinear`，不得混用名称。

这里固定的是当前算法实现及首选使用方式，不更改物理推进代码或旧卡解析缺省。
省略算法键的旧卡仍使用 Boris/linear；新的 2.0 基线必须显式选用上述配置。
外磁处理中的 Boris 子步骤不等于把整体粒子—场耦合改为 Boris 基线。

`conservative-source + quintic-compensated` 保留为备选对照；此前“动量匹配”简称
不代表已证明严格总纵向动量守恒。网格、束团长度、宏粒子权重和 CPML 厚度仍按工况设置，
本版本不把某个测试的 w=355 或横向网格设为所有物理问题的统一值。
束团输入优先沿用已验证的独立六维随机取样；不得重新引入沿 z 克隆横向相空间的加载方式。

固定时保留的验证结论：

- 三点核与五次补偿的两份100k自洽弯铁对照已完成，场分布及相应 LW 参考符合程度、
  规定轨迹近似和各统计口径以原报告为准。三点核末面固定 lab 管残差为约−0.262%/−0.313%。
- 当前独立随机 w355 六段 FEL 的完整固定 lab 管残差仍为三点核约26.51%、
  五次补偿约37.56%；版本固定不宣称该问题已修复。计算系含数值通道的离散加和闭合
  与实验室系物理账本闭合分别表述。
- 近场与辐射场仍不能普遍可靠分离；保留完整 E/B 与原有端口、侧流、时间端盖定义。
  原生 Puffin 边界展示的0.457%中央残留和6.76%复场范数差限于无粒子横向边界测试，
  不能直接解释生产 FEL 增益误差。

2.0 同时固定当前交付身份：总物理/PPT包 `physics_delivery_with_ppt_guide_20261117_r1.zip`
及 Puffin 净图包 `puffin_boundary_explanation_20261117_r4.zip`。图和视频维持当前净图样式；
这些数据包保持原位，以外部冻结清单的 SHA256 标识，不复制大结果到源码仓库。

源码归档取自标签的 Git 树。固定前已存在的未提交说明/脚本单独保存在工作区补充快照，
不混入发布提交，不改写用户原文件。冻结动作只更新版本、示例和文档，未新增物理仿真，
也没有把历史二进制冒充为由2.0标签新构建的程序。

**English:** APRL 2.0.0 freezes the current implementation and recommends
`conservative-source + linear-binomial3` explicitly. The legacy parser fallbacks
remain Boris/linear. Quintic compensation remains a comparison option, not a
guarantee of total momentum conservation. Existing laboratory energy-budget
limitations remain part of the release record. The tag and source archive identify
the committed release; pre-existing workspace edits are preserved separately.
