# APRL 2.0.0

本版整合当前代码到main，并以v2.0.0标记正式发行身份。早先未发布的同名本地源码快照
保存在历史归档及archive/v2.0.0-source-freeze-20261117标签下，不作为本版构建验收的替代。

## 两种受支持算法

默认且首选能量守恒＋三点核：`particle_coupling: conservative-source`、
`longitudinal_shape: linear-binomial3`。另一选项为`quintic-compensated`，
即此前称作“动量匹配”的五次补偿；该名称不构成严格总纵向动量守恒保证。
两者要求`current_filter: none`。省略算法键也选择三点核。旧Boris耦合、
简单linear、linear-notch和独立compensated-bilinear滤波在输入阶段拒绝，
没有旧算法开关或静默回退。解析外磁子步中的Boris步骤属于保留算法内部处理，
不是一个可选择的整体Boris耦合路径；底层数学回归仍可测试这些例程。

示例[完整输入卡](../../config/example.yaml)，以及
[三点核](../../config/profiles/v2.0-three-point.yaml)/
[五次补偿](../../config/profiles/v2.0-momentum-matching.yaml)配置片段。
片段需复制进完整工况卡，程序不自动合并配置文件。

## 适用结论

主[中文README](../../README.zh-CN.md)和[English README](../../README.md)
集中给出适用范围，不把全量图集塞进源码发行包。真空/CPML/漂移/冷束团等参考
是各自受控工况的结论。两份独立100k的自洽弯铁与匹配窗口、坐标、孔径的规定轨迹LW
对照良好；三点核完整lab管末值残差约−0.262%/−0.313%。

独立随机w≈355六段FEL的lab物理差额仍为三点核26.51%、五次补偿37.56%。
计算系完整离散账闭合不等于lab物理闭合。版本发行不消除这些已知限制，
也不把无粒子Puffin横向边界试验或近场扣除当成生产FEL修正。
宏粒子权重、网格、时间步、束团长度、孔径和CPML必须按目标物理量收敛。

## 构建和交付

版本文件VERSION和CMake project均为2.0.0；`aprl --version`和`aprl --help`
在进入MPI前返回版本/两种算法。每次运行的manifest保存aprl_version、实际源码提交
和解析后的耦合/核，包含五次补偿名称。

发布构建开启完整后处理、独立生成器、OpenMP和可选移动窗，并以
`ctest -L required --output-on-failure`执行必需回归。安装到独立前缀后验证实际
安装程序的两种算法与退休算法拒绝、动态库、版本和小型端到端输出。
详见[验收复现说明](../RELEASE_ACCEPTANCE_2.0.md)。完整物理图/原始H5不进入
运行包；已有科学结果原位保留。源码包可按站点MPI/HDF5重新构建；二进制包
有构建平台/依赖要求，不宣称跨任意Linux或MPI ABI直接通用。

原生Elegant SDDS转换器需额外官方SDDS库，是条件构建的可选组件；
没有该库时发行记录明确列出未构建，不用不完整解析器替代。HDF5输入、
文本转HDF5及各正式场后处理不依赖该可选组件。
