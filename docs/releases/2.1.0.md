# APRL 2.1.0

2.1 固定 Cowan 移动窗下的三项束场处理。默认纵向三点方案同时在水平方向 x 平滑；y 保持线性。通用输入沿用常规侧层启动。随版十万电子同步辐射工况默认选择带纵向均值修正的四侧 OSIRIS 式启动，另可选原左壁初态。[实算输入与使用方法](../../examples/beam_cpml_100k/README.zh-CN.md)

## 合入的改动与实测效果

| 改动 | 改到哪里 | 同工况已验证的效果 |
|---|---|---|
| 横向三点平滑 | 对 x 的线性形函数卷积一次 [¼, ½, ¼]。同一形状用于电荷、电流、粒子取场和移动窗参考供场。 | 十万电子横向核单独对照中，35.24 cm 屏上 3.75 µm 数值波的幅度降至原来的 3.16%。两次配对的平均推进耗时为 1272.47 → 1273.90 s。 |
| 纵向注入边界 | 开启 `inlet_charge_match` 时，新入窗切片继续按实际电荷满足离散高斯定律。Cowan 磁场更新读取的外半格法向电场在物理孔径内采用相对平移参考的奇延拓。 | 已测水平细网在 448 步内的入口指数增长得到抑制。该细网末屏背沿的近轴电场误差从 40.35 降至 1.498 MV/m；原网格同指标为 0.946 → 0.953 MV/m。 |
| 四侧 CPML 启动 | 对指定匀速束、离散网格和吸收层预算六个交错场和八条卷积记忆，含四角和纵向均值续接。在首次磁场更新前装入外圈，随后按原 CPML 推进。 | 同束早期第 1–36 步的整张末屏上，纵向磁场 cBz 的 RMS 从左壁方案的 2.250 降至 0.147 V/m。四侧修正与左壁方案都随束团数据包交付。 |

纵向边界的具体表达为 $E_{z,-1/2}=R_{z,-1/2}-(E_{z,+1/2}-R_{z,+1/2})$，其中 $R_z$ 是原平移参考。几何入口面处的两个半格平均值与参考场平均值相同。这个开关针对纵向移动窗入口，与横向四壁的 CPML 启动分别生效。

## 辐射基准与已知限制

- 完整自洽弯转基准使用十万电子、每侧 16 格 CPML。35.24 cm 的实验室屏在半径 75 µm 的 716 个像元上，第 167–312 步总电场相对完整 Liénard–Wiechert（LW）理论的误差为 2.824%。逐样本扣除理论速度场后，相对加速度项的误差为 3.497%，有符号波形余弦为 0.999430。主脉冲、晚窗和入口束外探针使用不同的归一与时窗。
- 新启动主要降低启动磁场。在同工况对照中，第 321–448 步的电场相对 LW 总场误差，左壁方案为 7.355%，四侧修正为 9.285%。按默认初态运行仍需把晚期电场差计入误差预算。
- 侧层对束团共动近场的匹配仍有限。匀速、完全无侧损的十万电子在第 0–160 步的入口屏与 LW 相差 62.59 kV/m RMS。将侧壁移出该窗的离散传播范围，同一批像元相差 5.83 kV/m。第一个明显的回传脉冲来自横向负 x 侧壁。现有对照仅测出侧层初态和持续近场驱动的合计贡献。
- 原始探测量为 E/B。低频近场与辐射的通用自动分离、长期任意几何的近场吸收，以及独立随机电子束六段 FEL 的完整实验室系能量闭合，均为开放问题。版本沿用已有 CFL、采样和网格收敛要求。

## 配置与兼容性

| 键 | 取值与用途 |
|---|---|
| `mesh.transverse_x_shape` | 随 `linear-binomial3` 默认在 x 启用 `linear-binomial3`；显式设为 `linear` 可恢复原 x 基函数。五次补偿使用线性 x。 |
| `mesh.moving_window.inlet_charge_match` | 设为 `true` 使注入切片电荷匹配与法向虚格修正同时生效。 |
| `mesh.moving_window.open_transverse_reference` | 使初始参考场和后续的移动窗供场采用开放横向参考。需同时开启 `reference_through_cpml`，关闭 `reference_surface_current`。 |
| `mesh.moving_window.cpml_startup` | 通用默认 `standard`；随版束团的首选为 `osiris`，可选 `left-20056`。两种预计算初态均配 `cpml_startup_directory`，相对路径以输入卡所在目录为基准。 |

预计算包绑定电荷、速度、初始位置、格距、时间步和吸收层配置。更换束团或网格需重新计算相应的初始场和记忆。输出和参考目录遵循原本的运行目录约定。以 `aprl --version` 和运行清单核对版本与实际使用的方法。[2.0 固定记录](2.0.0.md)

## 构建与核验

使用支持并行 HDF5 的 MPI 工具链、yaml-cpp、FFTW 和 CMake。以下命令构建正式程序并运行 required 回归。

```sh
cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_COMPILER=mpic++ \
  -DBUILD_TESTING=ON -DAPRL_ENABLE_MOVING_WINDOW=ON -DAPRL_PORTABLE_INSTALL=ON \
  -DAPRL_BUILD_POSTPROCESSORS=ON -DAPRL_BUILD_SASE_BUNCH_GENERATOR=ON
cmake --build build-release -j4
ctest --test-dir build-release -L required --output-on-failure
cmake --install build-release --prefix "$PWD/runtime"
"$PWD/runtime/bin/aprl" --version
```

两种纵向核均进行真实单进程和双 MPI 小算例，并检查探测输出与账本。2.1 的专项复核另覆盖 x 三点的电荷连续性、沉积与取场的做功一致性、真实移窗后的入口虚格，以及跨 MPI 分块的 CPML 启动场和记忆。使用十万电子实算时需单独解压对应的束团数据包。
