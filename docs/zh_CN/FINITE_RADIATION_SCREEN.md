# 有限距离辐射屏

在实验室的固定横截面上，逐像素计算已模拟粒子在真空中直接产生的 Liénard–Wiechert 加速度电场和磁场。结果保留符号、偏振以及不同电子之间的相位。可以直接输出时域 THz 波形，无需从 PIC 总场扣除速度场或指定频带。主网格的总场继续驱动粒子。发生在物理区内并实际改变粒子动量的自场力也会进入轨道辐射。

推进器只保存时域 E/B，不分配或累加复频谱。频率和傅里叶变换均由独立离线工具处理；未开启 `radiation_screen` 时不构造屏累加器。

## 启用

在普通 APRL 配置的顶层添加下面一段，即可使用正常的 `aprl run.yaml` 入口。这个例子对应 35.24 cm 的 5×5 屏，像素中心覆盖正负 55 µm。到达时间以实验室绝对秒计；请根据本工况的入射时钟、飞行时间和脉冲长度设置时窗。

```yaml
radiation_screen:
  output_file: radiation.h5
  nx: 5
  ny: 5
  x0_m: -0.000055
  y0_m: -0.000055
  dx_m: 0.0000275
  dy_m: 0.0000275
  z_m: 0.3524
  time_origin_s: 1.175479871478288e-09
  time_start_s: 1.175477871478288e-09
  time_step_s: 4.0e-17
  time_bins: 512
```

`x0_m`、`y0_m` 是第一个像素的中心。推进只累计时间格上的 E、B，每张屏写入一份时域文件。三个分箱参数 `time_start_s`、`time_step_s`、`time_bins` 都必须给出。仿真结束后可任意选择频点。

旧输入卡兼容其中的 `frequencies_hz` 列表，有时窗时它只作为 `requested_frequency_hz` 写入文件，供后处理选取默认频点。旧卡若只设置了频点，需要先补上覆盖信号的到达时窗与格宽。连续运行支持正常关闭，checkpoint/restart 和 `ballistic_outside_transverse` 模式仍沿用本探测器的原有约束。

## 每个受力子步如何贡献到屏

设第 j 个已经提交的 Boris 子步的实验室端点为 (t₀, r₀, u₀)、(t₁, r₁, u₁)，其中 u = γβ。对每个像素位置 X，按子步中点计算 R = |X − rₘ|、n = (X − rₘ)/R。实验室到达时钟满足 dT = (1 − n·β)dt。对子步冻结几何、对动量变化积分，获得该步电场的带符号时间面积

```text
F(n,β) = n × (n × β) / (1 − n·β)
A_E = q / (4π ε₀ c R) · [ F(n,β₁) − F(n,β₀) ]
A_B = n × A_E / c
```

该式来自对 LW 加速度项乘以 dT 后积分。每个像素、每个子步重新计算几何；屏距可以和轨迹几何尺度相当。用上述同一个 n 评估子步两端保留了纯速度恒定时的精确零响应。实现使用稳定的 γ−n·u 表达式和动量差来处理强前向束射。

宏电荷取自推进器。时域用两个端点的实际到达时刻 T₀、T₁，把 A 按与各时间格的重叠比例分配，再除以格宽。各时间格的场乘格宽再求和即为本窗的零频场积分。子步内的角度、几何和到达相位需要分辨；加密时间输出无法代替加密粒子受力子步，前向短脉冲尤其明显。

积分采用物理粒子激活后的力学子步。守恒耦合的迭代试算不重复计入。终止事件使用程序的物理边界时刻；若它位于某个子步内部，则对该子步的位置和 u 取线性前缀。出界后按惯性延续时，加速度贡献为零。CPML 载流子的电流衰减不产生屏信号。若真实装置在出界后还有磁铁或粒子仍显著受力，需要将那段真实轨迹也纳入辐射源范围。屏模型采用真空传播，腔壁散射、电介质响应、独立入射波和网格反射属于总场诊断。边界误差若在粒子出界前改变其实际轨道，仍会通过轨道影响这张屏。

## 从屏文件读取波形

HDF5 根属性 `complete=1` 表示完整关闭。`E_time`、`B_time` 为双精度数组，布局是 `[到达时间,y,x,xyz]`，单位分别为 V/m 和 T。坐标见 `time_s`（格中心）、`x_m`、`y_m` 和属性 `z_m`。

```python
import h5py

with h5py.File("radiation.h5") as screen:
    assert screen.attrs["complete"] == 1
    ex = screen["E_time"][:, 2, 2, 0]  # 中央像素的 Ex(t)
```

## 在后处理中计算频谱

可在另一台安装了 Python 3、NumPy 和 h5py 的机器上处理。以源码目录为当前目录，下面的例子计算 0、1、100 THz，并写入新的 HDF5 文件。

```shell
python3 postprocess/finite_screen_spectrum.py radiation.h5 spectrum.h5 --frequencies-hz 0 1e12 1e14
```

安装版提供同名命令 `finite_screen_spectrum.py`。显式指定的频率优先；省略 `--frequencies-hz` 时，工具使用时域文件里的 `requested_frequency_hz`，也识别带时域数据的旧屏文件里的 `frequency_hz`。输出路径须为新文件。只有复谱的旧文件可以继续读取其既有频点，计算其他频点则需要相应的时域数据。

对每个像素、每个电磁分量，记第 j 个时间格的平均场为 gⱼ，格宽为 Δt，格中心为 Tⱼ。将每个格的场取为常数，按实验室时间和正号相位精确积分得

```text
G(f) = Δt · sinc(π f Δt) · Σⱼ gⱼ exp[+i 2π f (Tⱼ − Tref)]
sinc(x) = sin(x)/x ，sinc(0) = 1
```

默认相位原点沿用原始屏的 `time_origin_s`，也可用 `--time-origin-s` 指定。文件中 `E_spectrum` 和 `B_spectrum` 布局为 `[频率,y,x,xyz,实部或虚部]`，单位 V·s/m 和 T·s。`frequency_hz` 是请求的频率轴。频点可随时重选，不占 PIC 粒子推进时间。这个变换的输入是已保存时窗内的格平均场。应让时窗覆盖脉冲，并使用能分辨所关心最高频率的时间格。有限时窗决定区分相邻谱线的能力；增加频点数量只会把同一个谱取样得更密。格内未保存的变化或窗外信号无法从文件重建。

## 预估代价

设 S 为有动量变化的已提交宏粒子子步总数，P 为屏像素数，Nₜ 为到达时间格数。PIC 的辐射累计工作约随 S×P 增长，还取决于每段覆盖的时间格数。各 MPI 进程分别处理本地粒子，通过 OpenMP 分摊像素工作。结束时将波形归约，由根进程写盘。双精度时域数组每进程为 48PNₜ 字节，另有轨迹批和工作缓冲，内存不随频点数增长。离线直接计算 F 个频点的工作量为 O(PNₜF)，与原束团粒子数无关。

根属性 `committed_substeps`、`accelerated_segments`、`clipped_substeps` 分别为物理子步数、实际参与辐射累加的子步数和终止截取子步数。`max_accumulation_s` 是各进程中最大的累计内核时间。`storage_bytes_per_rank` 记录屏累加器容量。
