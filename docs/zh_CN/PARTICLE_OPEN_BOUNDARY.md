# 考虑 CPML 的粒子开放边界

## 目的

CPML 内表面是物理粒子区域的终点。进入其后的粒子不应继续贡献轨迹或探测器数据，因为吸收层是数值区域而非观测区；但若立即删除其电荷，会破坏离散连续性方程，留下静态场并激发向外传播的数值脉冲。

程序因此把“物理粒子”和“数值载流子”分开：前者精确终止在第一个 CPML 入口，后者是一个很小且不输出的记录，在 CPML 内输运并衰减剩余电流。没有 CPML 的面则在计算域外表面继续使用电荷守恒开放边界。

## 从物理粒子到数值载流子

对每条从 `x_old` 到 `x_new` 的已推进轨迹：

1. 找到它与已开启 CPML 内表面或计算域外表面的第一次相交；
2. 用现有一阶电荷守恒轨迹沉积器沉积从 `x_old` 到交点的物理段；
3. 若启用轨迹输出，在 CPML 入口写入精确终止事件，并从此停止粒子面参与；
4. 用弹道数值载流子接管同一时间步的剩余部分。它只保存位置、冻结的坐标速度、电荷与电流权重，不做场采样、Boris 推进、轨迹输出或探测器工作；
5. 用衰减后的权重沉积载流子段；载流子到达外表面时，使用与开放边界回退路径相同的虚拟向外电流闭合清理残余电荷。

转换处没有停顿一个时间步。精确命中棱或角时按确定规则选择第一个面，保证事件和电荷只计数一次。

## 匹配电流衰减

载流子速度冻结在 CPML 入口。沿其实际相对论变换系路径，电流权重更新为

```text
w(t + dt) = w(t) exp[-integral sigma(x(t)) / epsilon_0 dt].
```

其中 `sigma/epsilon_0` 与场 CPML 使用同一分级电导率衰减率；若 x、y、z 多个吸收层同时有效，则各方向速率相加。路径积分使用三点 Gauss–Legendre 求积，只要线段位于同一多项式分段内，对当前三次电导率渐变就是精确的。跨 z rank 分割的线段保留其全局时间分数，衰减不会在新 rank 上重新开始。

线段电流沉积使用线段中点处的权重。这只是数值吸收装置，不是电子穿过材料的物理模型。CPML 的 `kappa` 和复频移 `alpha` 仍只属于场更新，不进入粒子电流匹配律。

## 外表面清理与无 CPML 回退

残余载流子到达外边界时，程序先沉积最后一段域内电流，再通过虚拟法向电流导出终端 CIC 电荷。若终端密度为 `rho_face`，虚拟链路满足

```text
(rho_after - rho_before) / dt + div(J_inside) + div(J_out) = 0,
div(J_out) = rho_face / dt.
```

该虚拟链路位于 E/B 网格之外，不是额外 Ampere 源。没有 CPML 的面上，物理粒子直接走这条外表面路径。小到舍入误差量级的残余载流子权重会被丢弃。

## MPI、内存与输出

内部 z-rank 接口是迁移面，不是损失面。物理粒子和载流子都能继续进入相邻 rank。载流子传输包含未完成线段的起点和全局时间分数，从而保持沉积与衰减连续。

每个载流子含八个浮点值；当前标量类型下为 64 字节。模拟只保存本地载流子向量、峰值数量以及各类边界的六个面总量，不分配稠密面数组，也不执行粒子边界 I/O。面统计只在结束时归约一次。轨迹文件含精确 CPML 入口事件，但绝不含载流子样本。

## 停止与解释

- 粒子进入 CPML 后立即离开有效粒子集合，载流子不会延迟 `after-last-element`；该模式表示物理粒子计算完成即停止。
- 若希望所有物理粒子离开后仍保留电磁振铃，应使用目标足够靠后的 `reference-center-z`；此时 Maxwell 继续推进，载流子继续提供衰减电流。
- 任何边界处理都不负责区分辐射场与近场；辐射重构应使用保留的物理轨迹或实验室系场探测面。
- 进入 CPML 是域损失诊断。频繁进入或损失高权重粒子通常说明物理孔径可能过小。
- 可选相对论 Poisson 初始化能够提供满足 Gauss 定律的初始自场；边界连续性无法补救被关闭、未收敛或本身不一致的初始场。

正常结束时，日志会分别报告进入 CPML 的物理粒子、直接外表面逃逸、残余载流子清理、带符号电荷和峰值载流子内存，并按 `x-`、`x+`、`y-`、`y+`、`z-`、`z+` 分面统计。
