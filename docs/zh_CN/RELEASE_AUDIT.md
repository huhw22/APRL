# 发布状态与生产计算要求

本文规定已实现范围、已知限制和生产计算要求。冒烟测试成功仅表示软件可以运行，不表示各类辐射结果已经达到物理收敛。

## 能力矩阵

| 区域 | 当前状态 | 正式使用说明 |
|---|---|---|
| 粒子输入 | 已实现 | Parallel HDF5 v4 保留固定 Elegant 面到达事件，并按每粒子自身速度同步；v3 偏移和旧 v1/v2 可读，支持相对权重。官方 SDDS C++ 工具直接按页和 ID 转换，无中间文本；旧分块文本工具保留。 |
| 自生成束团 | 测试用途已实现 | 确定性、无相关高斯，指定总电子数和宏粒子数；不是束流制备模型。 |
| 相对论变换 | 已实现并审计 | 计算系时间零锚定重构实验室束头，变换束团居中于数值盒；很大的虚拟实验室事件跨度只作诊断，不作为入口漂移约束。SI E/B 与光前动量往返检查已覆盖。 |
| 网格几何 | 已实现并审计 | YAML 只提供整数 `cells` 与物理 `cell_size`，总尺寸用乘法，MPI 薄层偏移/数量保持整数；拒绝旧长度除分辨率推导。 |
| Maxwell/粒子循环 | 无种子路径已实现 | 直接 SI E/B Cowan-z 或 Yee、Boris、电荷守恒电流沉积和 MPI 迁移。弱集体粒子/辐射能量符号与尺度一致；密集束团账本可测但尚未生产收敛。 |
| 场边界 | 无种子 Cowan 已实现 | 紧凑 CFS-CPML，含几何检查和粒子载流子处理；种子 TF/SF 与 Cowan/CPML 尚未实现。 |
| 粒子边界 | 已实现 | 真实历史在 CPML 入口终止；不输出载流子衰减电流并于外表面导出残余电荷。 |
| 停止与部分输出 | 已实现 | 支持按最后元件和参考中心停止；交互 SIGINT/SIGTERM 关闭成可读不完整输出，throughput 不轮询信号。 |
| 实验室探测面 | 已实现 | rank 0 独占写缓冲场面和粒子面；关闭后不分配、不通信。 |
| 粒子轨迹 | 可选诊断已实现 | 足以做少粒子远场验证，但不适合作为 `10^7` 粒子的主辐射记录。 |
| 轨迹辐射 | 小规模已实现 | 角谱/积分谱、偏振/Stokes、可选窗口/系综互谱密度。 |
| 场面本底工具 | 多模型已实现 | 匀速本底重构和匹配基线振幅相减/功率比较均可用；退休仍是实验功能。 |
| 完整场面辐射分析 | 下游前向模已实现 | 多线程 FFTW 输出角谱/积分谱、Stokes、Hann 窗相干/涨落、全局横向相干/Gram 本征值、选定空间与双频 CSD，并有内存/输出保护。 |
| 粒子/场能量闭合 | 计算系账本与实验室报告已实现 | 可选 rank-0 账本记录粒子动能、内部 E/B、六面通量、移除粒子、规定做功和能散矩。实验室报告组合共位入口/出口原始带符号通量和匹配 `K=0`。三周期密集测试达到 99.23% 原始纵向闭合和 91.73% 所选前向频段；仍需孔径、网格、CPML 和长器件收敛。 |
| 初始粒子自场 | 相对论刚性束初始化已实现 | 分布式 CIC/Vay 相对论 Poisson 初始化 E 与电流一致 B，强制内部离散 Gauss 定律，推进前释放所有势状态。CPML 内表面为零势静态边界。速度展宽、宏粒子采样和边界距离仍需收敛。 |
| 粒子子步 | 已实现 | 自动 Boris 子步解析实验室器件；网格 E/B、电流沉积和探测节拍仍在 Maxwell 步，辐射带宽不变。 |
| 辐射频段预检查 | 可选轴上保护已实现 | 用户最大实验室光子能量变换到计算系；z 网格、Maxwell/电流步和各场面低于严格 Nyquist 时硬拒绝，质量余量只警告。横向包络、孔径、CPML 和宏粒子仍需物理扫描。 |
| 输出安全与溯源 | 已实现并纳入门禁 | 模拟及后处理默认拒绝已有输出。rank-0 清单保存原卡、源码/构建/MPI 和粒子输入身份；统一 `run_id` 与配置摘要连接全部 HDF5。 |
| 端到端后处理回归 | 已实现且必需 | 微型模拟驱动重构、场分析、轨迹辐射、匹配功率和实验室能量闭合，检查完成标记和有限关键量；后处理所有 YAML 映射拒绝未知键。 |
| 激光/种子注入 | **目标内核缺失** | 通用 Cowan/CPML TF/SF 是主要未实现源路径。 |
| 粒子退休 | 实验性 | 不严格电荷连续，必须匹配零辐射基线并做收敛测试。 |

当前剩余的功能缺口是 Cowan/CPML 上的通用激光/种子注入。无种子求解器和场面诊断已完成，但正式物理结论仍受下述收敛和模型门禁约束。密集束团全局能量闭合已经“可测”，并不等于已经收敛；本审计也不把实验性退休提升为默认主路线。

## 数值预检查政策

以下情况继续运行会明确违反模型或输入契约，因此是硬错误：

- Cowan-z 几何/稳定限制和 CPML/MPI 薄层几何；
- 正整数网格数、正有限单元尺寸、有限乘积尺寸，且每个 MPI rank 至少两个纵向单元；
- 初始束团位于首个元件作用区之前，并适合计算系纵向盒；
- 正有限粒子权重、电子荷质比保持、全局电荷归一到 `beam.input.electrons`；
- Lorentz 变换有限，实验室/计算系往返动量和 gamma 相对误差不大于 `1e-10`；
- 启用 CIC/相对论 Poisson 初始 Gauss 投影时必须收敛并通过后残差检查，全部 CIC 电荷位于内部零势顶点；
- 自动 Boris 子步足以让最快粒子分辨最短波荡周期，且不超过 `mesh.maximum_particle_substeps`；
- 开启 `radiation_resolution` 时，z 网格、Maxwell/电流步和每个场面的前向轴上严格 Nyquist；
- 探测器、退休、磁作用、停止和频率保护的放置规则；
- 所有 YAML 映射层级（包括关闭的可选块）使用严格键集合，拼写错误不能静默回退；
- 停止目标有限：无元件 `after-last-element` 被拒绝；纯探测器或无元件 `reference-center-z` 合法。

采样错误会报告 SI 与输入卡单位下最大 `dt`，Cowan-z 还报告最大 `dz`。几何错误会给出修正网格、初始束团参考或探测器位置，而非只拒绝。

以下只警告，因为可接受尺度依赖物理目标：

- Lorentz 往返误差高于 `1e-13` 但低于硬阈值；
- 单电子实验室能量舍入尺度 `epsilon*gamma_max*m_e*c^2`，并建议从逐粒子 gamma 以补偿/扩展精度累加小能损，而非两个舍入总能量相减；
- 关闭满足 Gauss 的初始场，或在远离束团平均静止系的 boost 中使用旧静电近似；
- 使用实验性退休；
- 开启账本后，最终残差相对初始计算系动能加场能超过配置容差；
- `mesh.duration` 小于步数量化的启动估计。参考中心停止的估计精确；`after-last-element` 只按初始粒子弹道估计。

探测器实际节拍会精确保存，频段工具拒绝超过 Nyquist 的请求。模拟器无法证明未声明的未来分析频段、横向孔径、CPML 反射或宏粒子表示已经收敛，这些必须参数扫描。

全局粒子损失等于某一场面能量有意不作为启动硬条件，因为它依赖孔径、其他边界辐射、规定场做功、束缚场和匹配过面。粒子面规范要求先逐粒子求 gamma 差再补偿求和，独立闭合报告明确列出限制。单电子等效控制的符号和尺度正确：50–100 eV、±0.26 mrad 轨迹远场含动能损失的 48.13%，±2 mrad 含 54.88%。`10^6` 电子测试由信号和 `K=0` 间不同集体/近场变化主导，不能简化为动能损失等于一个前向面通量。运行账本补齐储能、六面通量、移除粒子和规定做功；三周期受驱动控制闭合到交换尺度和的 3.85%（初始计算系动能加场能的 7.996%），所以仍需密集束团网格、宏粒子和初始 padding 收敛。

## 资源报告

`runtime.resource_monitor.enabled: true` 时，rank 0 写立即刷新的 `[resource]` 单行，适合重定向 Slurm 日志。启动报告包含：

- 操作系统测量的当前与峰值驻留内存；
- 模型估算的每 rank 最大与聚合分配内存，覆盖场、CPML、halo、粒子容量、探测器、轨迹、账本缓冲，以及启用时临时四薄层 Poisson；
- 未压缩场面与轨迹输出上限；
- 无种子情况下的短、不改变状态步进基准和乘安全系数墙钟上限。

周期报告含进度、耗时、当前/峰值内存和剩余时间上限；最终报告记录实测循环秒/步与总墙钟时间。模型不声称预测文件系统竞争、调度干扰、后期迁移峰值或提前物理停止；两个安全系数必须针对目标机器、MPI 分解和代表输入校准。
