# 实验室系粒子轨迹 HDF5 输出

## 文件布局

轨迹输出采用每个 MPI rank 一个 HDF5 文件：

```text
<directory>/<basename>-rank-00000.h5
<directory>/<basename>-rank-00001.h5
...
```

不存在共享文件写入，因此 rank 之间不会争用轨迹文件。每个 rank 独立缓冲记录。交互模式可以周期提交可读前缀；正常完成把文件标记为完整，协调信号停止则保留已提交前缀并标记为不完整。

`/trajectory` 组属性 `format_version` 为 `2`。一维复合数据集 `/trajectory/records` 包含：

| 字段 | 含义 |
|---|---|
| `particle_id` | 全局稳定的宏粒子标识 |
| `source_id` | 输入粒子源标识 |
| `time_s` | 实验室时间，单位 s |
| `position_m[3]` | 实验室系 x、y、z，单位 m |
| `proper_velocity[3]` | 无量纲实验室系固有速度 `gamma*v/c` |
| `charge_C` | 带符号宏粒子电荷，单位 C |
| `weight` | 输入相对宏粒子权重，仅作诊断元数据 |
| `event_type` | 下表所列记录类型 |
| `boundary_face` | 下表所列边界编号；无边界时为 `-1` |

## 事件类型

`event_type` 的稳定整数取值为：

| 值 | 名称 | 含义 |
|---:|---|---|
| 0 | 普通采样 | 按节拍采样，`boundary_face=-1` |
| 1 | CPML 入口 | 物理轨迹在 CPML 内表面的精确终点 |
| 2 | 计算域逃逸 | 未经过 CPML 时，在计算域外表面的精确终点 |
| 3 | 粒子退休入口 | 实验性退休层入口的精确终点，`boundary_face=-1` |

边界编号为 `0=x-`、`1=x+`、`2=y-`、`3=y+`、`4=z-`、`5=z+`；HDF5 属性也保存这些映射，读取器无需只依赖本文档。

CPML 与退休层中的数值载流子不会产生轨迹记录。因此数据集可用于辐射重构，而不会混入非物理吸收区路径。边界事件可能落在两个普通采样时刻之间，重构粒子历史终点时必须保留。

## 采样节拍与辐射时间窗

`trajectory.rhythm` 按输入卡时间单位换算成秒，并作为相对论变换系推进中的节拍阈值。程序在第一个达到或越过阈值的完整 E/B 步采样，不把粒子状态插值回精确节拍时刻；随后每个样本分别变换到实验室系并写成独立事件。

所以该数据是事件表，而不是规则的 `[共同时间, 粒子]` 数组：

- 同一计算系时间步记录的粒子在变换后可拥有不同 `time_s`，因为实验室时间依赖粒子纵向位置；
- 粒子跨 MPI 薄层后会继续写入另一个 rank 文件，但 `particle_id` 不变；
- CPML 入口、退休入口和域逃逸事件可以位于周期样本之间；
- 记录按 rank 本地写入顺序追加，不按粒子或实验室时间全局排序。

辐射读取器只读取每个 rank 文件的已提交前缀，按 `particle_id` 重分配记录，再按 `time_s` 排序每条历史。线段速度由相邻实验室位置和时间计算；`proper_velocity` 仅用于诊断，不替换位置弦。

对远场方向 `n`，相关时间坐标不是单独的 `time_s`，而是约化观测者时间

```text
u = time_s - n dot position_m/c.
```

前向相对论辐射中 `time_s` 与 `z/c` 几乎抵消，因此有效 `u` 区间可能远短于实验室模拟时长或 `trajectory.rhythm`。远场工具会报告中心轴上内部折点的实际 `u` 范围。正式时间窗应根据该范围和更细轨迹节拍的收敛确定，不能仅从 HDF5 行数推断。

## 关闭时的成本

当 `trajectory.enabled: false` 时，不构造轨迹写入器、记录缓冲区或文件。边界统计与载流子推进独立于轨迹输出开关。
