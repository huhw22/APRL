# 实验室系能量诊断

本文给出纯波荡器运行的物理解释层，并与计算系运行账本严格分开。规定的静态实验室磁元件满足

```text
W_magnet,lab = 0.
```

其 Lorentz 变换后的电场可在计算系做非零功，因为能量与纵向动量在 boost 下混合：

```text
Delta E' = gamma_b (Delta E - beta_b c Delta p_z).
```

实验室静磁铁有 `Delta E_magnet=0`，但可交换动量，所以计算系能量分量不必为零。该做功是计算系账本所必需的，却不是新的实验室能量源。

## 低成本可分离量

两个固定实验室粒子面给出稳定的粒子动能变化；实验室场面给出其前向孔径、时间窗和频段内的辐射；匹配 `K=0` 运行控制集体自场演化和数值漂移：

```text
L_signal  = particle kinetic loss in the undulator run
L_control = particle kinetic loss in the matched K=0 run
L_device  = L_signal - L_control
E_forward = collected forward radiation in the selected band
R_lab     = L_device - E_forward
```

若在两个粒子面同位置保存原始总场，可用很小额外输出构造更强纵向控制体诊断：

```text
F_z = [(W_exit - W_entry)_signal
       - (W_exit - W_entry)_control],
W_plane = integral dt integral_A S_z dA.
```

`S_z` 带符号。`F_z` 同时保留穿过平面的粒子近/束缚场和辐射，可直接与 `L_device` 比较而无需预先决定何者是辐射。振幅扣基线后的前向谱回答更窄的辐射问题。`F_z-E_forward` 可从离散数据观测，但不唯一等于近场能量，还可能含频段/角度排除和二次分解交叉项。

`L_control` 是**空间电荷加数值控制**，不是储存近场能量的直接测量。`R_lab` 可含差分束缚场、侧向/后向辐射、漏孔径/频率和数值误差。精确拆分需要闭合实验室辐射曲面或等实验室时刻三维 E/B；后者在 boost 模拟中昂贵，因此不是默认输出。

`energy_closure` 只读取实验室粒子面和辐射产品，不与等计算系时间储能混合。格式版本 3 包含：

- 以代表宏粒子质量加权的入口/出口平均 gamma 与 rms 能散；
- 信号、零磁场控制及逐粒子匹配差；
- 收集的前向辐射和未解析实验室余量；
- 可选信号/控制入口、出口原始带符号 Poynting 通量；
- 明确标志：近场变化未被直接测量，能散不是独立能量库。

## 快速解析估算

`lab_frame_energy_estimate` 不加载模拟数据即可给出运行前尺度：

```bash
cmake -S . -B build
cmake --build build -j --target lab_frame_energy_estimate
./build/lab_frame_energy_estimate config/lab_frame_energy_estimate.yaml
```

对长圆高斯束使用

```text
lambda_q = I / (beta c)

U_bound / L_bunch ~= (1 + beta^2) lambda_q^2 / (4 pi epsilon0)
                      * [ln(b / (2 sigma)) + EulerGamma / 2].
```

`1+beta^2` 同时包含实验室电自场和磁自场能。绝对量需要用户提供外尺度 `b`，可代表束管半径或有限束长截断。横向尺寸按统一比例变化时：

```text
Delta U_bound / L_bunch
  ~= -(1 + beta^2) lambda_q^2 / (4 pi epsilon0)
      * ln(sigma_final / sigma_initial),
```

所以主导变化不依赖任意外截断。正尺寸变化表示膨胀，对应负储能变化。束缚场尺度正比 `I^2`，广义导流系数正比 `I/gamma^3`。半径扫描固定电流；纵向压缩或流强轮廓演化需另算。

波荡器参考采用角积分单电子结果

```text
dE / dz = r_e m_e c^2 gamma^2 K^2 k_u^2 / 3
```

和轴上基频

```text
lambda_1 = lambda_u (1 + K^2 / 2) / (2 gamma^2).
```

默认相干增强为 1，所以这是非相干参考，不是预聚束预测。仅给电流、gamma 和 rms 尺寸不能确定纵向 form factor；相干增强必须来自独立且有依据的 bunching 计算。

## 50 A 尺度测试

项目示例使用 `I=50 A`、`sigma_x=sigma_y=60 um`、`gamma=1174`、`lambda_u=2.34 cm`、`K=1.093`、`b=10 sigma`。未指定束团持续时间和器件长度，因此基本结果按每米平顶束团、每个波荡周期归一化；另列 100 周期示意。

| 量 | 估计 |
|---|---:|
| 线电荷 | `1.66782e-7 C/m` |
| 每米束团电子数 | `1.04097e12 1/m` |
| 每米束团粒子动能 | `99.9695 J/m` |
| 广义导流系数 | `3.62574e-12` |
| 基频波长/光子能量 | `13.5595 nm / 91.4373 eV` |
| 每电子每周期非相干损失 | `1.33337 eV` |
| 每米束团每周期非相干辐射 | `2.22382e-7 J/m` |
| 每米束团近似 E+B 束缚场储能 | `9.49023e-4 J/m` |
| 束缚场储能/粒子动能 | `9.49313e-6` |
| 每米束团 100 周期非相干辐射 | `2.22382e-5 J/m` |

绝对束缚场储能约为 100 周期非相干参考的 42.7 倍，但这**不是能量交换**，只有其变化有意义：

| rms 尺寸变化 | 每米束团的束缚场变化 | 绝对值/100 周期辐射 |
|---|---:|---:|
| `+1%` 膨胀 | `-4.97517e-6 J/m` | `0.2237` |
| `+10%` 膨胀 | `-4.76551e-5 J/m` | `2.1429` |

平均包络空间电荷力受到强相对论抑制，但大束缚场储能的百分比变化仍可影响能损诊断。预聚束相干辐射可能远大于非相干参考，应以模拟所得实验室账本为准。

## 已有输出回归

弱集体单电子等效算例中，零磁控制在报告精度为零，粒子损失 `5.93986e-21 J`；50–100 eV、±2 mrad 轨迹辐射为 `3.25979e-21 J`，占 54.88%。未解析 45.12% 可含有限频段/角接受，不能全归于近场。

`10^6` 代表电子算例中，信号粒子获得 `1.82555 nJ`，零磁控制获得 `65.2575 nJ`；匹配差给出名义 `63.4320 nJ` 器件相关损失，但 0–300 eV 前向场面只有 `3.63257 nJ`（5.73%）。控制交换绝对值为匹配差的 1.029 倍，94.27% 未解析，所以该旧紧凑算例应解释为集体场/数值控制主导，而不是把匹配粒子差称为辐射。

新的控制体测试使用 `gamma=1000`、128 宏粒子代表 `10^6` 电子、三周期 30 mm `K=0.5` 波荡器及匹配 `K=0`，入口/出口面位于 0 和 159 mm。延长时间使脉冲完整后：

| 项 | 能量 |
|---|---:|
| 信号粒子损失 | `5.902545 nJ` |
| `K=0` 粒子损失 | `-0.017060 nJ` |
| 匹配粒子损失 | `5.919605 nJ` |
| 匹配原始带符号纵向场通量 | `5.874187 nJ` |
| 原始残差 | `0.045418 nJ` |
| 振幅清理后的 0–300 eV 前向辐射 | `5.430281 nJ` |

原始纵向通量解释 99.23% 的匹配粒子损失，所选前向辐射解释 91.73%。二者差别是总带符号场输运与所选传播辐射产品的差别，不再是未知守恒失败。原始测试仍非闭合曲面，因为缺少横向通量和两面间等时储能。

时间窗扫描使原始闭合依次从 54.57% 升至 62.45%、83.38% 和 99.23%；保持起止不变只加倍纵向网格仍为 62.45%，证明该算例主误差来自探测时长而非 `Nz`。

## 正式解释建议

1. 在信号和 `K=0` 中，于磁作用区前后放置完全相同的实验室粒子面；
2. 使用相同电荷分布、初始自场、网格、时间窗、探测孔径和随机种子；
3. 先在 E/B 振幅层面扣基线，再形成前向辐射能量；
4. 在入口/出口同位置重构原始带符号功率，并确认时间窗含两个脉冲尾；
5. 运行 `energy_closure`，先检查 `L_control` 再解释 `L_device`；控制可比或更大时属于集体场主导，必须收敛；
6. 在孔径、频段、时间、粒子数、网格、初始场 padding 和 CPML 收敛前，把 `R_lab` 保留为未解析项。
