# 粒子子步进

粒子子步进在不改变 Maxwell 时间步和场存储的前提下，把解析磁元件中的轨道积分精度与场推进步长分离。它适合长波荡器或高次谐波问题，此时实验室系解析磁场需要比 E/B 网格更密的轨道采样。

## 自动选择子步数

启动时，程序用已加载粒子中最快者和所有平面波荡器中最短周期，计算一个实验室系周期内包含的 Maxwell 步数，然后选择满足下式的最小整数 `N_sub`：

```text
N_sub * Maxwell_steps_per_period >= particle_steps_per_undulator_period.
```

选定的子步数和实际每周期采样数会写入 rank-0 日志。`mesh.maximum_particle_substeps` 用于限制意外计算量；若所需子步数超过该值，程序会在场分配前退出，并给出两个选择：显式提高上限，或细化 Maxwell 步长（Cowan-z 情况下还会建议最大的 z 向 `cell_size`）。

## 一个场步内的行为

在每个 Maxwell 步开始时，程序只在粒子位置采样一次交错网格 E/B，并在全部子步中保持该网格样本不变。随后执行一系列相对论 Boris 推进，每个子步都在当前子步位置和时刻重新计算解析实验室系磁元件。这样粒子归属判断和 MPI 交换仍然每个 Maxwell 步只发生一次。

最后一个子步结束后，原有电荷守恒沉积器只沉积从本场步起点到最终位置的一条弦。探测器与轨迹节拍也仍绑定 Maxwell 步。程序不会建立子步数组、子步文件或额外 MPI 交换。

## 数值限制

子步进能够提高规定波荡器和外部解析元件的轨道积分精度，但它明确不会：

- 提高 Maxwell 时间带宽或场探测器的 Nyquist 光子能量；
- 在一个场步内重新采样自洽网格 E/B；
- 向 Maxwell 求解器暴露场步内弯曲电流轨迹；
- 代替场网格、宏粒子数、探测器孔径或 CPML 收敛研究。

因此，较大的子步数可能已经收敛解析元件轨道，而辐射场仍然欠分辨。正式输入卡必须独立地按照最高目标频段细化 Maxwell 网格和时间步。建议先固定场网格扫描子步数，再单独扫描场网格。可选 `radiation_resolution` 块会执行严格的轴向 Nyquist 检查并打印非约束性的质量警告，但不能代替这些扫描。
