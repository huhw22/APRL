# 纵向粒子精度优先：独立耦合诊断

本轮要求是保证粒子的纵向位置、动量和能量变化，而不只是保证真空波沿 z 的传播。横向允许的小偏移不能成为掩盖纵向假冲量的记账方式。本目录只含诊断器和独立一维原型，没有替换正式推进、沉积、供场或默认程序。

结果入口：`results/longitudinal_coupling_diagnosis_20261102/README.md`。理论与公式见 [METHOD.md](METHOD.md)。该工作仍未通过完整三维物理验收，不写入此前“正确结论”正文。

## 已确认的物理机制

原先的周期盒采用正负电荷、相同质量的两种粒子；它是隔离误差的数学对照，不是生产电子束。纯纵向版本横向均匀、无 B、无 CPML、无供场或移窗，场纵向动量恒为零，因此粒子总纵向动量应保持不变。这里也复现了假纵向冲量，排除了必须依赖横向 Cowan 色散才会出现这一项的解释。

在原匹配取场的纯纵向对照中，末态冲量差分别为：空间权重项 −4.758356915e−14 J、路径与端点时间配对项 −2.245106471e−15 J、Gauss 项约 1.21e−28 J。这里 J 是 cΔP 的单位，不是额外外功。空间项约占这一次末态差的 95.5%；不能推广为所有工况的固定比例。电荷连续性、Gauss 约束均在舍入附近。

原因是能量配对与纵向力配对并非同一条件：原线性电荷形函数对应的 Jz 及其功共轭 Ez 取场，在 z 方向是分段常数权重。它可以满足粒子功与网格 J·E，却仍对粒子相对网格的位置敏感。上一原型又给 Ez 加了 M_E,z=SxSy 权重；不能只凭该加权能量闭合就接受对纵向作用力的平滑。

## 新原型与独立物理参照

保持 cΔt=Δz，使用原有动量推进函数。只在独立一维模型中提高纵向形函数到三次、五次，并让电荷、电流、取场使用同一个局部补偿算子。补偿有两类，分别匹配原线性方法的低频响应、或匹配连续理论响应；结果中明确标记，不能混用其精度数字。没有施加横向动量或能量补偿。

独立一维线性基线与实际三维纯纵向对照的逐步 ΔK、cΔP 最大差分别为 6.12e−25、2.73e−24 J。新模型因而确实复现了已观察到的机制。

独立参考使用谱空间冷流体方程与粒子特征线，不使用 PIC 沉积、Cowan 取场或相同网格。参考自身做了空间和时间收敛检查。弱空间电荷对照中，末态逐粒子 u_z 的相对 L2 误差为：

| 纵向方法 | u_z 相对 L2 误差 | 最大绝对 u_z 误差 | 最大位置误差 |
|---|---:|---:|---:|
| 原线性基线 | 7.30997% | 2.6361e−7 | 2.7142e−11 m |
| 三次＋连续响应补偿 | 0.0106516% | 3.8485e−10 | 3.9611e−14 m |
| 五次＋连续响应补偿 | 0.0000972188% | 2.7119e−12 | 5.6863e−16 m |

相对 L2 分母是参考中真实的逐粒子纵向动量变化范数，不是初始总能量。模拟约 0.669 ps、周期域约 30.1 μm；该数字不是实际大电子束的误差预测。参考收敛的 u_z 相对 Linf 变化约 9e−13，远小于待比较差。

## 尚未通过的强、长与稀疏采样对照

仅看到弱工况一致还不够。在约 13.39 ps 的强空间电荷对照中：

| 方法／采样 | max\|cΔPz\| (J) |
|---|---:|
| 原线性，16 对电荷片、24 格 | 8.198998e−11 |
| 五次＋原响应补偿，16 对、24 格 | 2.596317e−13 |
| 同方法，16 对、48 格，Δt 同比减半 | 2.333018e−11 |
| 同方法，96 对、24 格 | 1.420574e−19 |
| 同方法，96 对、48 格 | 1.695522e−19 |
| 五次＋连续响应补偿，16 对、24 格 | 1.276403e−13 |

固定粒子数加细网格使纵向采样更稀疏，不能把它叫作充分的收敛。增加电荷片数量会改变微观采样，但总物理电荷、宏观初分布、网格、时间长度保持一致；仅用于诊断，不修改生产输入。

五次、16 对、24 格的余差分解中，空间项峰值 2.5963178e−13 J、时间项峰值 4.5028883e−20 J、迭代项峰值 5.87e−25 J。96 对时空间项降至约 1.42e−19 J。因此这组余差主要是空间耦合与采样敏感性，不能归咎于时间不同步，也不能靠允许横向色散来解释掉。

## 可以与不可以得出的结论

可以：纵向高阶且电荷／电流／取场一致的方案，在已经测试的弱、密集采样对照中，同时保留正确的粒子纵向响应与能量收支；解决方向比直接更改 Cowan 纵向传播更有针对性。

尚不可以：宣布所有粒子加载都通过、推断 4.5 m 的几百 eV／keV 问题已消失、把小的总能量残差当作纵向精度、推断全程序成本。真实束团的纵向采样、三维横纵耦合、参考供场、冻结／载流粒子、MPI 接口、活动窗边界及辐射频带仍需要单独验证。全程序尚未接入。

“把纵向误差放到横向”应指离散设计优先保护纵向，并定量验收横向代价。直接给每个粒子改 pz 后保持其原终态能量，需要新的 u_perp² 非负；在原纯纵向对照约 49.84% 的粒子步没有这种解。这只是否定这一种逐粒子补偿构造，并不证明所有各向异性算法不可能。
