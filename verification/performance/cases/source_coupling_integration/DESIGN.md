# 完整流程中的守恒源项耦合

用户授权先接入基础注入/移动窗/多rank功能，再复测既有空间电荷对照。开关为
`mesh.particle_coupling: conservative-source`；默认`boris`保持原推进。
不更换生产默认或重调理论、原输入、释放位置/动量、快速参考、保护格和原物理终点。

## 一个物理步

1. 原pending队列只准入本步到期的粒子，原磁场curl和横向CPML按原流程执行。
2. 保存旧E和相邻原生场面。以零J求一次原电场curl；边界预览暂算原CPML与
   原入口覆盖，随后恢复其电卷积历史和边界相位。只保存横向边缘及入口覆盖的
   稀疏场增量，不增加第二套全体积E/B。
3. 中间迭代复用原`pushDepositAndMigrate`，临时关闭探测器、轨迹和能量输出，
   恢复原粒子/载流子、损失/释放/边界累计计数。pending准入、移窗和物理时间不重做。
   最终电场由本轮完整原沉积及同一参考表面电流生成，共享J面按原规则累加。
4. 在仍保留最新试算E时，计算每个实际活动弦上的一致E/B，并缓存为下一轮取场。
   再撤回上轮J、重置沉积。必须保持这个顺序，不能在还原E后重新取下一轮的场。
5. 全rank共同检查无量纲力方程缺陷<1e-13，以及固定点功缺陷<1e-8，最多8轮；
   有活动推进时至少2轮。功缺陷为逐粒子`|q(Econsistent−Eused)·dx|`之和，
   分母用活动子步绝对自场功及一致场整弦绝对功之和。它是固定点判据，
   不能替代包含冻结源、退出和场算子通道的完整能量账本。
6. 收敛子步以缓存状态/功回放，正式释放/迁移/探测/轨迹只提交一次。
   通过交换旧E和零J波的缓冲，正式提交仍在原旧E上记录约束/表面源功，
   不再做第三次Lorentz求解，也不增加第二套全体积场。
7. 交换回零J波，撤回预览边界的稀疏增量；施加正式J并提交原CPML和入口边界。
   不再重算Cowan电场curl。CPML预览有额外运算，但其历史只正式前进一次。
   MPI接口curl在准备阶段完成，最后CPML提交与接口加法的顺序只存在浮点舍入差，
   必须用完整3D多rank场比较和独立离散账本核对。
8. 原移窗/新层电荷匹配/退出/固定lab诊断继续执行。无新吸收层或快照。

## 取场和诊断

局部平均速度方程沿用上一轮独立原型。旧E/新E及固定半步B提供完整一层原生MPI
续接，不在rank接口钳制取场坐标。试算中的跨rank释放仍走原激活迁移包。

正式回放生成实际粒子功和能量面子步端点。既有H5的Boris命名功字段在新模式下
保存新推进的实际功，方法名由run manifest明确，磁旋转项为0、算术余差另记。
冻结粒子与CPML载流子的约束源功在新模式下改用与原沉积相伴随的路径积分；
默认模式保留原估计口径。原Cowan数值通道与纵向边界账本保持。

## 先后验收

先构建和原78项回归；局部方程/伴随积分；非零3D场＋有J＋真实CPML历史＋移窗，
在1/2/4rank上对比原电场提交与新准备提交路径。再用原257步无磁/有磁卡验证
默认科学输出逐位不变、新模式真实释放/退场、4/16rank运行和账本。
然后用原32768宏粒子冷均匀球、内向聚焦球、冷球高斯以及三档低电荷卡，
保持原理论世界线、入射文件、各固定lab面、网格/guard/终点和输出节拍，
只改耦合方法及输出位置。首次受力前状态用原独立探针核对，不把入口面插值
可能出现的ULP差说成真实输入改变。

物理展示与程序验证分开。理论精度、交换账本、场数值通道与耗时分别报告；
不以账本闭合宣称整个物理解已验收，不以昂贵诊断掩盖额外耦合成本。
