# 五次纵向源／取场接入主流程（2026-11-03）

用户明确授权在独立分支接入并运行原4.5 m有磁／0.5 m无磁对照。本分支为 `wfollowm_dev/longitudinal-main-flow-20261103`，不替换默认程序、不推远程。上轮只是独立一维原型，本轮才接入生产主流程。

## 方案

在现有 `conservative-source` 主流程上新增：

```yaml
mesh:
  particle_coupling: conservative-source
  longitudinal_shape: quintic-compensated
```

缺省或 `linear` 保留原路径。开启时纵向电荷为五次B样条、纵向法向电流为四次B样条；横向仍为原线性权重。与独立原型的连续响应版本一致，对电荷、三分量电流和伴随电场取场使用同一个七点局部补偿。每个跨格子段四点Gauss积分覆盖三维多项式最高六次项。Cowan差分、磁场取样、原平均速度粒子推进、外磁场、子步、释放事件、探测面、CPML历史提交及MPI停止/watchdog保持。

新权重仅访问本地有限支持，不保留原一维验证代码的逐粒子全网格扫描。高阶电流在MPI边界外的贡献先归并到邻rank，再调用原共享面电流求和；粒子电场使用八层只读邻域，原磁场邻域保持。默认路径仍使用原一层邻域。

快速参考场同样采用补偿后的五次电荷。为避免41M粒子临时索引膨胀，新增参考源路径以纵向块做稳定计数分桶，只保存每粒子一个索引，逐块累积源；不展开48个贡献记录／粒子。原分块Cowan求解与缓存不变，参考元数据包含形函数身份。

新注入层匹配相同电荷权重。尚未进入窗口但其形函数已经覆盖入口的冻结粒子，只查看事件队列未来八步范围，计入其实际冻结轨迹电流及独立约束源功；不提前释放、不修改相空间、不扫描整个等待队列。

五次与补偿的支持宽于原线性模板，因此内部可信退出位置由原4+余量格改为8+余量格，位于既有128格上保护区内。活动窗口、参考网格、64/128保护底座、步长及总时间不扩大；实际粒子／场出口探测面仍保持4.5 m或0.5 m。该内部退出变化在几何审计单列，不能声称与旧版所有边界位置逐位相同。

结果总目录：`results/longitudinal_main_flow_20261103/`。

- `build-r1`：冻结源码构建，既有78 required；新增独立B样条／补偿对照、三维连续性、1/2/4rank电流与八层电场邻域、快速参考源与形函数元数据负控。
- `flow-r2`：原短漂移（16MPI×8、单节点）及短波荡器（32MPI×8、双节点），各旧程序／新程序线性／新程序高阶三组。关闭新选项应与原科学输出逐位一致；开启后检查首次释放相空间逐位保持、探测面完整、固定点功与力方程容差、离散场账本和正常收尾。
- `summarize_flow.py`：只读闭合短对照，比较同一80—160步区间的秒／步，保留单次配对限制，不外推大仿真或宣称物理验收。

`flow-r1`在辅助模块导入时失败，未进入PIC；修正依赖后使用新目录flow-r2。冻结的科学输入与旧结果不就地修改。

实际程序及源码身份以各次 `FROZEN.json`、`COMPLETE.json`、`SOURCE_IDENTITY.json`为准。编译使用冻结源码而非Git目录，revision可能为unknown；不冒称最终文档提交被重新编译。四份已有未提交的正确结论文档保持原内容，不随本轮提交。

## 物理边界

程序可运行与高阶电荷／电流配对通过，不等于真实逐电子物理已验收。连续冷流体比较只验证集体极限，不能要求有限单位电荷逐粒子完全服从连续解，也不能以加密分数电荷采样替换真实输入。本轮保留同一真实电子输入，输出供后续粒子能量、动量、两系账本与辐射谱对照。尚未声称之前大仿真能量异常已解决，或完整三维能量—动量同时守恒。
