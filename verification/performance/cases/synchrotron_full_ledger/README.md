# 同步辐射：三点核／纵向动量匹配与完整能量账本

复用已验证的完整账本程序 `sparc_six_full_ledger_20261112_r3/bin/aprl`，不改 C++、不构建或切换默认。
两个方法分别为 `conservative-source + linear-binomial3` 和 `conservative-source + quintic-compensated`。
本次用户明确启用自洽反馈；旧的七点核 LW 接受记录为无自场反馈，须保留这个物理差别。

每方法含原 20261111／20261112 两份独立 100k 单位电子样本的偏转和对应直线控制，共四例；
粒子原文件、网格间距与格数、时间步、磁铁、保护层、物理停止位置及原四个 raw 场面保持。
额外启用计算系逐步账本、严格离散算子账本、lab 能量／动量／应力、四侧场能流、时间端面存量、
子步粒子过面能量及侧向粒子输运。全频、完整记录，不加 Hann 窗或删去前后段来对账。

现有侧向粒子观察器的矩形以原点为中心。准备时将原网格和束流一起平移 x=-120 μm，
保持相对网格坐标；两种磁铁均为横向匀强偶极或零强度虚拟波荡器，物理场不变。
显示原实验室系坐标时给输出 x 加回 120 μm。该变换、输入 SHA 与其他卡差异写入 CARD_AUDIT.json。
观察世界管从 z=0.02 m 开始，位于冻结供场支持之外；四侧观察面位于横向参考表面电流内侧一格。
有横向粒子穿越时使用实际提交子步事件记录，不能预设其为零。端面与全部边界覆盖须在闭合后核验。

提交一个 40 分钟、独占 128 CPU 的短预检，再以 afterok 依赖提交两个 8 小时独占节点作业。
布局固定 16 MPI × 8 线程；每例 5400 秒硬限；保留 600／60 秒 MPI-free 收尾 watchdog 和 self,vader,tcp。
短预检是三组完整输入 40 步的有界运行，包含观察器 off/on 逐位对照和高阶观察器运行；
故意触发 duration 不足并核对闭合但未完成标记，不能把它标成完整物理结果。

使用 `prepare.py ROOT` 生成独立冻结目录，`job.sbatch ROOT preflight` 做门槛，
`job.sbatch ROOT linear-binomial3` 和 `job.sbatch ROOT quintic-compensated` 执行匹配的正式工况。
