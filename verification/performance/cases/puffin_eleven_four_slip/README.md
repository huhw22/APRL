## 统计定义

每周期保存原生全网格/全保留频带功率及1λ局部BF；每段出口保留完整节点场和粒子。
只在正常完成后分析，直接统计节点强度，不额外横向四点平均、不跨程序拟合幅度。
每出口给±560um孔径、共振±5%频带Rect/Hann能量及功率、载频谱密度、全束BF、中央窗口BF和10λ局部RMS。
Hann采用固定RMS窗约定（w除以sqrt(mean(w²))），这是已声明的谱窗定义，不是按另一程序匹配幅度。
功率分母取所统计窗口的实际N×dt；整段与中央窗分开，绝不把中央能量除以全束时长。
中央窗口固定为入口retarded坐标[1.5S0/c,2.5S0/c]，预留总滑移及首尾余量；它不保证抛物线束有平坦功率平台。

原生全域功率与孔径内窄带功率是不同观察量，图例分开；保留Parseval、粒子数/总电荷核查。
