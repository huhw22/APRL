# MPI 粒子负载均衡：整数纵向分片

本功能在完整推进步之间调整各 MPI rank 拥有的纵向整数网格区间，使粒子较多的区域使用更多 rank。活动窗口总长度、格距、时间步、粒子输入、释放事件和物理方法保持。它默认关闭；当前验收目标是程序结果一致及计算成本，而不是建立新的 FEL 或空间电荷物理基准。

本轮保留原 `conservative-source` 能量配对、Cowan 显式场推进、沉积、四个横向 CPML 面、参考供场和固定 lab 探测面。短 FEL 卡仍使用每个场步 7 个粒子子步；原固定点收敛规则保持，最多 8 次迭代，要求 `self_force_defect < 1e-13`、`relative_fixed_point_work_defect < 1e-8`。已完成的七周期卡379步中，336步使用3次迭代、42步使用2次、1步使用1次；本优化没有把迭代固定为3次。

## 设置

```yaml
mesh:
  particle_coupling: conservative-source
  longitudinal_shape: linear-binomial3
  moving_window:
    enabled: true
    # 沿用该工况原有的参考域、活动窗和保护层设置。
  mpi_particle_balance:
    enabled: false
    interval_steps: 5
    minimum_cells: 3
    minimum_improvement: 0.1
    frozen_weight: 0.2
    field_cell_weight: 0.0
```

此处只列相关片段，不是一张独立可运行的计算卡。

| 字段 | 默认值 | 含义 |
|---|---:|---|
| `enabled` | `false` | 启用整数分片调整；要求 MPI×1，即每个 rank 一个计算线程 |
| `interval_steps` | `5` | 每隔多少个完整场步检查负载，包括第0步 |
| `minimum_cells` | `3` | 每个 rank 至少拥有的活动纵向网格数；输入验证允许至少2格 |
| `minimum_improvement` | `0.1` | 预计最大负载至少降低这个比例才改变 cuts；同等最优值保持原 cuts |
| `frozen_weight` | `0.2` | 尚未释放粒子和 CPML carrier 相对活跃粒子的调度权重 |
| `field_cell_weight` | `0.0` | 每格场工作的基线权重；0表示自动使用 `Nx*Ny/64`，显式正数则采用该值 |

这些权重只进入调度器，不改变粒子的质量、电荷、宏粒子权重、场值或任何物理源项。每个 rank 的设置和线程数必须一致。程序检查 moving window、conservative source 及现有方法兼容条件；不支持把这一开关直接用于原 Boris 流程或多线程 rank。原 conservative-source 对 Cowan、无电流滤波及其它组合的限制仍然适用。

活动窗口必须至少容纳 `MPI ranks * minimum_cells` 格。本功能不自动加长窗口来满足 rank 数，也不缩短仿真或改变探测面。默认3格配合下述3层通信可使用相邻 rank 通信；2格仍有通用跨多个 rank 的正确路由，但可能增加通信成本。单 rank 时不做重分片。

关闭开关不构造负载直方图、不求新 cuts、不搬迁场或粒子；整个新程序是否有可测的关闭成本仍应由同资源计时确定，不能以科学输出逐位相同代替耗时测量。

## 调度模型与整数 cuts

每个全局纵向格子的估算成本为

\[
w_i=N_{i,\mathrm{active}}+
\alpha\left(N_{i,\mathrm{frozen}}+N_{i,\mathrm{carrier}}\right)+\eta,
\]

其中 `alpha=frozen_weight`，`eta` 是非零场工作基线。尚未到入窗事件的 pending 粒子仍保留原事件队列，不按其总存量当作每步活跃工作。这里统计粒子处理数量，而不是按其电荷加权。

保持全局格数 `N` 和 MPI 数 `P`，求整数切点

\[
0=c_0<c_1<\cdots<c_P=N,
\qquad c_{r+1}-c_r\ge n_{\min},
\]

以尽可能降低

\[
M=\max_r\sum_{i=c_r}^{c_{r+1}-1}w_i.
\]

`particle_balance.h` 对候选最大成本作二分，并用滑动队列检查严格的连续区间可达性。最小片长大于1时，简单选择“当前能放下的最长前缀”会漏掉可行分片，因此未采用该贪心规则。小数组由独立的精确动态规划对照，检查目标值、最小／最大片长、零成本、同值选择和异常输入。

一次阈值检查为 `O(P*N)`；最多80轮浮点区间细化。只在最终重建 cuts 时保留 `O(P*N)` 父指针。调度改善门槛比较的是当前和候选的最大模型负载，不是实测秒数。自动 `Nx*Ny/64` 只是未标定的启发式，不能保证为当前工况的最佳值；场、缓存复制和 CPML 工作可能需要更高权重。单格中的粒子不能继续按空间分片拆开；全局固定点迭代、场推进和通信开销也不会随这个目标值等比例下降。

## 在完整步之间搬迁状态

新 cuts 只改变存储归属，坐标和时间不插值。重新分片按全局整数 z 索引搬迁：

- 全部9个原生 `E/B/J` 分量；
- 全部12个 CPML 历史槽（无 z CPML 对应项为空），保留原历史值和系数关系；
- 粒子、冻结状态及 CPML carriers；
- 场边界的步号、窗口偏移、回调和累计诊断状态。

共享节点采用右侧 slab 的唯一 donor，最末全局节点归最后一个 rank；新共享面仍保留所需的两份表示。搬迁前不一致的旧共享场或 CPML 节点会使所有 rank 拒绝，而不是平均或修正它们。重分片不记作物理场能流入或流出。相对账本仍使用完整同 cohort 粒子动能变化的一个固定分母；比较两版时共用 baseline 的分母。

粒子反馈、沉积和跨面观测仍在原推进流程中执行。工作数组、入窗完成器及固定 lab 探测器随分片更新；全局参考生成和 pending 输入没有改为新的物理模型。全粒子驻留及初始化 rank 0 的参考准备峰值内存并不由此消除。

## F3 的三层通信

F3 形状和反馈系数仍是 `(1,2,1)/4`。理论上，CFL=1的一格轨迹只需两层非零支撑。但生产格距下的世界坐标归一化可能产生一个极窄的额外 cell 区间，带来真正非零的第三层权重。原磁采样还会访问精确零权重的角点。因此生产采用**理论两层加一层 IEEE／访问保护**，保留原磁采样顺序，既不把小权重当零，也不在 MPI 界面额外裁剪。

原8层路径保留给关闭均衡的 F3、其它宽形状（quintic-compensated、linear-notch）及对照；普通 linear 仍使用原有较窄路径。生产3层和8层的电流、约束电功、初始／残差粒子受力和 replay 均有独立对照；测试还要求实际非零第四层访问拒绝。理论推导、r4真实第三层权重和特殊端点说明见 [COMPACT_HALO_PROOF.md](COMPACT_HALO_PROOF.md)。

## 原8层整程序对照与成本

已完成的 `smoke-r1/` 使用较早的8层均衡方案、32 MPI×1，包含漂移、一周期波荡器和七周期 w64 FEL。每组都有旧程序、新程序关闭均衡、新程序启用均衡三份完整数据。

旧程序与新程序关闭开关的科学字段逐位一致。启用后的粒子身份／电荷／质量／权重精确保持，场和粒子变化、相对账本差值在该轮预定严格容差内。三组都实际发生过重分片。该证据属于早期8层方案，不能替代最终3层整程序验收。

[独立闭合数据复核](/public/home/wfollowm/APRL_Workspace/results/mpi_particle_balance_20261106/independent-final-review-r1/SMOKE_R1_REVIEW.json)重新读取了三组所有场帧和全部子步粒子面，核对原生粒子ID、species/weight、复数 bunching 和共同粒子变化分母。场的最大峰值归一差约 `4.35e-14`，全平面复数 bunching 最大绝对差约 `4.49e-14`；原始证据126个文件的大小／mtime保持。该复核未读取最终运行中数据。

## 脚本与日志

`build.py`／`resume_build.py` 记录完整构建或仅测试修订的身份；`prepare*.py` 只准备独立卡，`freeze_campaign.py` 冻结输入；`run.py`／`run.sbatch` 运行有总时限的作业，完整关闭后才调用 `analyze_closed.py`。性能汇总由 `performance_report.py` 完成。任何脚本失败、超时或缺少完成标记都不视为科学通过。

`aprl.log` 中的 `[particle-balance]` 记录实际 cuts、模型最大负载、搬迁时间和粒子包大小；manifest 保存启用状态、周期、最小片长和源 halo 层数。启用性能采样时，另看 `coupling_total`、`coupling_cache`、`coupling_residual`，并保留已有场、粒子、通信与诊断阶段。rank CSV记录逐步固定点收敛。原600/60秒关闭 watchdog、作业内网络选择和正常集体停止规则保持。

本轮不切换默认程序、不修改已运行作业、不自动追加测试或提交全量仿真。

## 适用边界与前缀性能检查

本功能按纵向整数格分配，不能把同一格内的粒子继续分给多个rank。当前原生MPI重分发要求每rank粒子字节包小于INT_MAX；超出时明确拒绝，没有实现分块大包。重分片后逐rank账本不再代表固定空间控制体，内部守恒应按每步汇总所有rank。

默认场成本是尚未通用标定的启发式。它不是最佳配置保证：`performance-r3`的两对完整计时均慢约16%，其中胖空片的场工作成为后半程瓶颈。未来准备器可用`--field-cell-weight`指定纯调度成本，并以相同值生成static/on两组；该值不改变电子电荷或宏粒子物理权重。当前2000调度权重实验等待完整结果。

真实60360290电子的短前缀只做150个完整场步。`prepare_full_prefix.py`保留原合法physical stop与参考域，duration取149.5dt；`freeze_prefix.py`安装专用runner。预期duration异常出现在所有本地writer关闭及readiness集体同步之后，只允许严格识别的exit1，H5/discrete的physical complete保持0，source-coupling CSV闭合标记为1 150。完整事务、有限值、ID及账本通过后仅发布`PREFIX_COMPLETE`，不发布`PIC_COMPLETE`。普通full reader仍只接受complete1。部分束团通过不代表整个束团或37周期FEL完成。`test_prefix_contract.py`含32项离线正负控。
