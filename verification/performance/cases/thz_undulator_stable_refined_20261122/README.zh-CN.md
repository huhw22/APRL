# THz 三组：横向加密及稳定步长重启

用户于本轮授权细化横向场网格并启动三组。旧目录及失败记录保留。

- APRL 2.1 本地 main 核心 d279179，16 MPI × 8 线程，每组独占一节点。
- 同一 80,000 个宏粒子，电子束总电荷 −0.7 nC；5 cm × 20 波荡器。
- 频率 8.19 / 4.095 / 2.73 THz，K 与此前相同。
- 横向 180 × 120，dx = dy = 32 μm；dz = 19.2 μm，c dt = dz。
- 全横向范围 5.76 × 3.84 mm；四侧 CPML 每侧 20 格，厚度仍为 640 μm。
- 入口局部齐次模约束 dz/H ≤ sqrt(sqrt(2)−1) ≈ 0.643594；本轮 0.60，Qmax = 1.79096949 < 2。
- 三组在前向 8.19 THz 波长上分别约 99.61 / 70.41 / 57.47 个场网格点。
- 虚拟屏保持 25 × 19，x ±2 mm、y ±1.5 mm；时间采样 3.052503 fs，即实验室 8.19 THz 周期 40 点；输出加速度项 E/B，频谱离线计算。
- 每组预计最大 3846 / 4406 / 4975 个 Maxwell 步；实际按全部粒子离开最后磁元件停止。

每组流程：新网格原生参考 → 四侧 OSIRIS 场和卷积记忆重算 → 256 步完整自洽短测 → 正式辐射运行 → 离线频谱和完整性验证。短测与正式计算均启用电荷匹配入口、保守源耦合、x/z 三点平滑和原生固定点容差。短测不输出辐射、粒子屏或轨迹，仅检查闭合的场审计及耦合收敛记录。

短测本身预期触发 duration 上限并返回非零；只有精确达到 256 步且通过检查才进入正式计算。preflight 同理精确达到 9 步。正式运行必须以物理停止条件退出 0，四个粒子屏均需 80,000 个唯一 ID 后才标记完成。

`check_stability.py` 的场范数警戒线只拦截灾难性早期增长：峰值/初值 < 1e10，末 32 步能量比中位数 < 1.2。它们不是精度或物理验收标准，不改变原生受力/功固定点阈值 1e−13 / 1e−8；场范数也不是辐射能量。入口局部稳定条件和短测通过均不代表整轮或网格收敛已验证。

## 日志

各组 `f0-div-N/STAGE` 标记当前阶段；`slurm-任务号_N.log` 是总日志。原生初始化日志在 `f0-div-N/preflight/aprl.log`，短测日志在 `f0-div-N/stability-gate/aprl.log`，正式推进日志在 `f0-div-N/aprl.log`。后者仅在正式阶段创建。

源输入、参数、脚本与程序 SHA 由 `INPUT_SHA256.json` 冻结；每个任务启动前复核。新网格不使用旧网格初态。

## 重现

这是上述固定结果目录的物化模板。复制 scripts/ 和 case.sbatch 到新的结果目录，更新 case.sbatch 的目录；先复制原始 beam.h5、beam.sdds-export.bin 和 fnv1a64，再执行 prepare.py 并冻结输入清单。prepare.py 以结果目录的父级 results/ 推导 workspace，不能直接在源码目录执行。改变网格或束团必须重新生成参考及 OSIRIS 初态。
