# Puffin 原生边界传播控制

针对上一版只有规定输入的一次算子作用、无法说明真实传播过程的问题，本例调用既有冻结库的 DiffractionStep、AbsorptionStep 和原生 FFTW 路径，进行无粒子的实际沿程传播。

同一倾斜高斯光束、40 µm横向间隔、相同原生衍射步，比较81²原生吸收、81²关闭吸收、401×241大域及481×321更大域。先以原生平面波相位/范数对照检查路线，再比较大域间及独立傍轴高斯解析场。传播300步、约2.1m；每5步保存共同81²区域复场，每步保存y=0剖面与全域/中央范数。

本例采用原生单波长周期分支以关闭纵向末端掩膜，单独测试横向边界；不是生产时域FEL、不是纵向掩膜修复，也不含电子响应。关闭吸收的返回可能是FFT数组周期绕回，不能自动叫物理反射。单独记录负kx模式作为横向方向诊断。

计算只在Slurm节点运行，一独占节点/4MPI×1、20分钟分配、每例180秒外层限制与60秒强杀余量，无自动重试。只链接新的试验入口，不改或重建生产Puffin库。prepare冻结脚本/来源，run依次闭合例后分析，最后渲染实际传播视频。后续人工目视后才能替换PPT主交付；旧说明包保留。
