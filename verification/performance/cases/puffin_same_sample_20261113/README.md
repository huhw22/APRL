物理样本固定为已经完成 APRL / GENESIS 对照的 `w64-a`，不增加种子。

## 为什么用 Puffin

此前同事件 GENESIS 控制证明，当前硬裁剪脉冲的边带输出对任意光学切片边界敏感。
Puffin 不使用辐射慢变包络近似、波荡器周期平均或这种光学切片模型，可以检查另一套直接解析载波的源与场计算。
它仍采用傍轴、前向传播近似，忽略空间电荷和尾场，因而不能替代完整 Maxwell PIC 自场验证。[官方说明](https://ukfels.github.io/puffinDocs/)

GENESIS 的表示敏感性是一项已确认的数值来源，但不证明 APRL 所有剩余差异均正确；BF 偏低尚未解释。
本次目的首先是检验 7 周期就出现的绝对频带能量差及频谱形状。

## 束流事件与单位

采用原始独立随机 1,954,743 条宏粒子、实际权重 63.9999943727，对应物理总电荷约 20.043797 pC。
读取原始 source ID、过面位置、到达时间及 proper velocity，不使用 Puffin 随机生成、quiet loading 或额外噪声。
为从磁入口开始推进，以原事件精确弹道传播共同的 1 cm 场外漂移：

\[
x_e=x_0+0.01u_x/u_z,\quad y_e=y_0+0.01u_y/u_z,\quad
t_e=t_0+0.01\gamma/(c u_z).
\]

这是同一世界线到另一个固定平面的表示，不是每个粒子重新置为共同起点。
APRL 在这段漂移中可含自场，Puffin 没有该物理项，因此不会假称两者进入磁场前已有自洽自场等价。

Puffin 原生 `electrons` 为 N×7，顺序为 x̄、ȳ、z̄₂、p̄x、负 p̄y、Γ、χ̄。
本机方程的复横向动量为 `px-i py`，不能直接把两方向原 proper velocity 同号复制进去。
映射使用 `x̄=x/sqrt(Lg Lc)`、`z̄₂=c_code(t-t_anchor)/Lc`、`p̄x=ux/K`、`p̄y=-uy/K`、`Γ=γ/γr`。
χ̄由每条实际宏电荷除以本机 `qe_code*npkbar` 给出；真实总电荷不改变。
输入额外保存 source_id 供入口审计，但当前 Puffin 输出不传播 ID；后处理不将其原生局部 BF 冒充原中央固定 ID 群的局部 RMS BF。

内部选用 ρ=0.005 作为明确的坐标/场单位定义，宏电荷通过 χ̄保持；没有调用 `qFixCharge`，没有按结果调源强。
这不属于跨程序幅度匹配。原代码物理常数的字面量存在 default-real 到双精度的提升，转换器按**实际编译常数**核对单位；不能用近似 npkbar 造成隐藏的电荷变化。
编译探针逐个核对 Lg/Lc/η/κ/npkbar，后者是原生权重单位而非经验修正。

## 磁场必须匹配

Puffin 默认 `qUndEnds=true` 使用两周期线性端部，APRL 使用一周期平滑端部，并含 `-(h'/ku)cos(ku z)` 修正。
直接套默认卡会改变电子轨迹和启动辐射。[官方端部说明](https://ukfels.github.io/puffinDocs/sections/undulatorfields.html)

保留 `/public/home/wfollowm/Puffin` 原仓库（当前 157f473）不变，在结果目录保存逐文件 SHA256 的源码副本。
副本仅给外磁场增加显式选项 `aprl-ramp77`：

\[
B_y/B_0=\cosh(k_u y)[h\sin(k_u z)-h'/k_u\cos(k_u z)],\qquad
B_z/B_0=\sinh(k_u y)h\cos(k_u z),\quad B_x=0.
\]

h为首/末一周期 `0.5[1-cos(πd/λu)]`，全长始终为 77λu。
K=2.060074987322757、λu=0.028 m；未用 GENESIS 的 rms aw 代替峰值 K。
传播、RK4、源沉积、取场及原磁场选项的代码保持；CMake 额外加入外磁场探针。
原版与增加选项版先对同一官方固定 CLARA 算例执行回归，随后验证实际编译磁场的 15,005 个轴向/离轴点。
提交前探针相对 APRL 公式最大绝对误差 5.77e-14（以 B0 为单位），实际坐标缩放差 2.22e-16；作业中重复核对再准入。

## 分辨率、边界与统计

- 三维时域模式 `meshType=0`，不使用单波长周期模式。
- 横向 81×81 节点、40 µm 间距，节点跨度 3.2 mm；比较孔径沿用 ±560 µm。
  Puffin 默认横向吸收区为每边 16 节点；输入给出中央 49×49 节点，H5 束流路径又按实际粒子范围自动设置驱动内域（入口日志为41×25），并可在推进中重排。物理网格与比较孔径保持；它与 APRL 的 CPML6 不是同一种边界算法。
- `nodesPerLambdar=21` 对应每波长 **20 个间隔**，不误读成 21 个网格间隔。
  纵向保留整束 231λ及两端至少 48λ余量，使用 FFT 友好的 6561 节点，约 328λ跨度；不裁掉边缘辐射来取得一致。
- 粒子 RK4 每波荡器周期 80 步，衍射步长为 1/4 周期；首次短测不宣称网格/步长收敛。
- 明确设置 `qFilter=true, sFiltFrac=0.3`：低于约 0.3 倍本机参考频率的分量在衍射步骤被滤掉。
  本轮只比较共同共振频带 ±5%，不能据此检验 APRL 的低频速度场；低频滤波对反馈的可能影响保留为限制。
- 原生 `aperp` 的实部/虚部是两个横向实场分量，不是 GENESIS 单偏振的复包络。
  用其实际时间序列作单边傅里叶变换，并检查 DC/Nyquist 计数和 Parseval；不能套载波包络的能量系数。
- 三程序使用同一组 513 个物理频点、Rect ±5%、实际 SI 场与共同孔径。保留同频点积分及 257 点粗积分检查，不拟合幅度。
- 后处理从实际沉积几何恢复横向节点坐标 `(j-(N-1)/2)dx`；旧 vizSchema 的部分范围元数据可多半格，不直接当作场采样坐标。
- Puffin 给出前向横向场。APRL 对照使用此前保存的代数前向分量；它仍可能含前向速度场，不能称完成近场分离。

## 运行与准入

原准备作业19765的官方原版/增加选项版算例及外磁场探针通过，但195万粒子的首个快照输出超过240秒预检上限，未进入物理推进；其原目录、冻结卡和失败日志完整保留，不作为辐射结果。

替代预检19766复用了已通过的两程序算例与编译磁场探针，执行相同N×7布局的独立HDF5-MPI写入探针：OMPIO未在20秒内完成，ROMIO在3.718秒完成，全部数值闭合回读正确。使用ROMIO后，真实1954743粒子的入口快照成功写出，全部七列按唯一x匹配逐位保持。
随后，导入预检卡因1步/周期与1/4周期衍射不兼容，`NINT(.25)=0` 后 `MOD(...,0)` 整数除零；这是预检卡配置错误，未产生物理短测结果。原快照在报错前已由程序写完并关闭，作业结束后独立回读通过，不把未闭合的失败文件当科学结果。模板已将此预检改为4步/周期。

有效正式作业19767：独占一节点128物理核、128 MPI×1，复用全部已闭合的导入/软件/磁场/IO证据及对应SHA，保持原7周期物理卡（80步/周期，20步一次衍射）、粒子、磁场、程序和网格，单独启动物理短测。
MPI-IO选择不改变方程或相空间，不通过放宽粒子验证来绕过快照问题。
入口回读要求所有七列在按唯一入口 x 对应后逐位保持；只检查输入转换文件本身不算准入。
`NATIVE_VALIDATED.json`、`SMOKE_VALIDATED.json`、`FIELD_VALIDATED.json` 与 `STARTED.json` 分别记录这些关口。

主计算上限 2700 s、整个作业 1 h；无自动重试、追加种子或追加 77 周期任务。
冻结身份清单包括原生输入、卡、源码/脚本/程序与依赖的逐文件 SHA256。
按既定偏好，确认有效启动后停止主动监控，等用户唤醒；不读取运行中的 H5。
成功退出后自动分析闭合输出，写 `analysis/RESULT.json`、`comparison.csv`、`comparison.png`，并保留所有原始场和粒子文件。
