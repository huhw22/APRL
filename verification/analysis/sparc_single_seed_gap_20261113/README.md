## 已确认的原因与尚未解释的差异

对当前非零电流处硬裁剪的短束团，GENESIS 将片内载波源压缩为一个包络节点，会产生明显依赖光学切片原点的边带输出。
仅将同一批真实粒子的切片边界平移半个波长，并补偿相位、保留物理到达事件，±5% 频带能量便变化约 54%。
这是一项已经用单变量控制确认的表示敏感性，足以达到此前 PIC/GENESIS 能量差的量级。
这里没有重新分配粒子相空间，也没有重新出现横向克隆。

BF 偏低尚未由这个原因解释。换边界后 GENESIS 的中央固定 ID 群局部 RMS BF 仍高于 PIC，且略升。
半片平移后的频带总能量接近 PIC，并不意味着它是更正确的参考解：出口的载频谱强度、聚束和横向模式仍未全部一致。

## 算法来源

直接核对本工况冻结的 `source/fixed/src/Core/FieldSolver.cpp:18–61`：每光学片分别累加 `current/N * sqrt(faw2)/gamma * (sin(theta)+i*cos(theta))`，在横向双线性沉积后供给该片光场。
每片只存一个复包络源；后续滑移/传播作用于片节点。下式采用与输出复共轭一致的载波符号，略去公共相位因子。

取 `ω=ω0+Ω`，真实事件 `t_p`、片节点 `t_m`，任意相同实权重 `a_p`。精确源为

\[
B_{\rm exact}(\Omega)=\sum_p a_p e^{-i\omega_0t_p}e^{-i\Omega t_p}.
\]

当前包络片源等价于

\[
B_{\rm slice}(\Omega)=\sum_m e^{-i\Omega t_m}
       \sum_{p\in m}a_p e^{-i\omega_0t_p}.
\]

差别是把片内 `exp[-iΩ(t_p-t_m)]` 设为 1。载频 `Ω=0` 必须一致，离载频的相干叠加未必一致。
对于缓变、片内接近均匀的密度，未保留的细节通常较弱；硬裁剪生成的两端部分片则有强共同相位源，对任意切片原点敏感。
这不是导入损坏：真实相空间、载波相位和总电荷全都可以正确，而边带源仍不等价。

一个可独立推导的例子是平坦束流在 `q∈[a,a+M]` 硬截断，M 为整数波长，令 `ν=Ω/ω0`：

\[
 B_{\rm exact}=\frac{e^{2\pi i(1+\nu)a}(e^{2\pi i\nu M}-1)}
 {2\pi i(1+\nu)M},\qquad
 B_{\rm slice}=\frac{(e^{2\pi ia}-1)(e^{2\pi i\nu M}-1)}{2\pi iM}.
\]

因此非零谱点的功率比为 `|B_slice/B_exact|²=4 sin²(πa)(1+ν)²`。
当前两端实际落在 `a≈0.563`；在载频附近该比值约 3.85。
原点平移 λ/2 后变成 `a≈0.063`，仅有约 0.155。两者代表相同连续束流，却给出很不一样的边带源。
载频处平坦整数长束的两者本身均为零，不把这个比值当载频的非零功率。

当前抛物线平均密度配合声明的参考直线飞行，独立积分给出 `exact/slice` 的 ±5% 初始源功率积分比 0.260234；24/48 阶 Gauss 积分相差仅 `6.36e-15`。
对**真实采样事件**直接逐粒子计算（不是平均密度替代），结果为：

| 源权重 | 精确/原切片源的频带平方积分比 |
| --- | ---: |
| 1 | 0.3519433 |
| 1/γ | 0.3519468 |
| Gaussian 横向 100 µm 模式 /γ | 0.3587715 |

同一归一化定义下，载频源复幅度差仅 `1.09e-16`。
这些是初始源诊断，尚未包含真实轨迹、辐射 Green 函数、衍射或 FEL 反馈，**不能乘到输出能量上作为补偿**。
离线对齐边界也是敏感性检查，不是选择正确参考的准则。

## 已排查的统计口径与物理解释边界

- 改用同一连续频点后，原边界 PIC/GENESIS 的能量比仍为 0.51912 / 0.44923（7/77 周期）。513 与 257 点积分相对差最大约 `2.21e-6`，频率格不一致不足以解释差异。
- ±160/320/560/800 µm 孔径和固定 Gaussian 模式诊断已保存；扩大孔径并未自动消除原差异。没有拟合任意横向模式或幅度。
- `F_x±=(Ex±cBy)/2`、`F_y±=(Ey∓cBx)/2` 的前向平方减反向平方与原净 Poynting 逐点代数一致。±560 µm 下 PIC 反向项/前向项仅约 `1.6e-10 / 1.2e-12`，两种能量定义几乎相同。超相对论速度场也可能进入前向项，这不构成近场分离。
- 上轮空间电荷理论提供了数个百分点的 BF 抑制候选尺度；本次半片控制没有消除 BF 差。不能把原全部能量差或 BF 差直接归因于 LSC，也不能据总能量碰巧接近认定其已被排除。
- 两组 GENESIS 出口的载频与 BF 并非相同；单个切片原点不是精确参考。下一步若要提高基准可信度，应先处理非零电流处硬裁剪及片内包络源表示，再讨论剩余空间电荷、粒子形状与模式响应。此轮未改生成器、未追加物理工况。
