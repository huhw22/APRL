## boost离散账本

逐步汇总16个rank，以与场推进匹配的原生场能和离散curl边界交换记账：

\[
R'=\Delta K'+\Delta U'_{\rm native}+Q'_{\rm curl}
-W'_{\rm prescribed,constraint}-I'_{\rm inlet}-M'_{\rm remap}
-T'_{\rm time,current}-C'_{\rm Cowan}-A'_{\rm CPML}.
\]

源功还独立分为 prescribed_boris_work、boundary_source_work、frozen_constraint_work 和 carrier_constraint_work。已复核原诊断与新离散账本之间的空间定义／通量定义／时间／Cowan桥接恒等式，以及粒子功与场电流功的拆分。

三点核、动量匹配的最大累计纯场算子差额分别为2.89×10⁻²⁰ J、1.24×10⁻¹⁷ J。最终约6 pJ的总差额主要是粒子与电流功的对应差额。动量匹配的时间配对项+4.273495 mJ与Cowan项−4.268290 mJ很大且大幅抵消；这些是离散通道，不能当成辐射能。

## lab数值能量—动量账本

whole-cowan记录完整的begin、fixed_end、remap三个阶段。其原生参考场能H′与cP′包含原算子的配对时间层，不能当成普通连续场能。

\[
\begin{aligned}
R_H&=\Delta H'+Q_H+W_J-S_H-C_H,\\
R_P&=\Delta(cP')+Q_P-P_J-S_P-C_P+G_E+G_B,\\
R_{\rm lab,slice}
&=\Delta K_{\rm lab}+\Gamma[\Delta H'+\beta\Delta(cP')+Q_H+\beta Q_P
 -S_H-\beta S_P-C_H-\beta C_P+\beta(G_E+G_B)].
\end{aligned}
\]

S包括8类逐操作源及remap。全rank汇总后的R_H、R_P通过独立重算与存储值核对；局部rank包含接口交换，不能逐rank强令其为零。lab组合的最大累计纯场恒等式差额只有4.04×10⁻²⁰ / 9.90×10⁻²⁰ J。

剩余量与独立测量的

\[
\Delta K_{\rm lab}-\Gamma\sum(W_J-\beta P_J)
\]

一致。这里是定位到已测量的两项之间，并没有把差额补到场能里。能量部分Γ(ΔK′−ΣW_J)分别为+342.480 / +362.562 µJ，纵向动量部分Γβ[Δ(cP′)+ΣP_J]为−339.324 / −359.685 µJ，两者相加才是+3.156 / +2.878 µJ。

这两部分仍含外磁场在boost系中的功与冲量、冻结／规定源及耦合差异。**正式长作业未开启实际粒子子步的force-geometry细分轨迹**，因此不能进一步把剩余量唯一归因于纵向电力、磁力、外磁场推进或取场。现有数据保存了这些场通道，但“全量账本”不等于所有粒子力分项也已记录。

## 独立固定lab管：沿用打包对话的完整几何

依据旧打包材料中的 [THEORY_LAB_COMPLETE](THEORY_LAB_COMPLETE_previous.md)，本次将粒子侧流与非空粒子时间端盖显式加入：

\[
\Sigma_{\rm lab}=K_{\rm out}-K_{\rm in}+K_{\rm sides}
+K_{\rm cap,late}-K_{\rm cap,early}
-W_{\rm in}+W_{\rm out}+W_{\rm sides}+C_{\rm late}-C_{\rm early}.
\]

固定管从z=0.03 m延至各段出口，横向x,y∈[−520,+520] µm。两面共用τ=t−z/c门，场时间端盖须用C=∫(u−S_z/c)dA dz。冻结源加9ΓΔz支持界只到z=0.01260 m；横向规定电流在±560 µm，移动窗边界也在管外。连续lab外磁场静态、E_external=0，所以物理外电功为零；这不证明离散推进对外场的lab功误差为零。

所有场积分使用完整公共时间门与全频总场，不做Hann、不切FEL频带、不去启动或尾场、不扣近场。E与前后半步B平均到同一时间层，再按Yee位置对齐并变换。每个场面还积分常数1检查覆盖，最大相对覆盖误差9.79×10⁻¹⁶。独立制造守恒流与旧Python几何逐面核对通过；该检查只验证积分几何，不能证明PIC物理收敛。

粒子使用真实已提交子步过面事件及标量端点动能插值，不从插值后的三动量重算γ。逐ID核对入口、出口与侧向穿越的有符号计数：前五段所有ID的计数都闭合，所以粒子早晚端盖为空。至第五段：
