# 物理交付总包与 PPT 指导

本目录提供本地交付模板。`PPT_GUIDE.md` 是结果总结与 PPT 制作指导：保留用户规定的直观传播图、两参考系有符号完整账本、单轴随程曲线、完整理论假设和纯公式推导偏好，列明当前数值与适用边界。它是制作指导，不生成实际 PPT。

`package.py WORKSPACE OUTPUT ZIP` 读取已复核前半部分 ZIP、最新六段能量/理论 ZIP、纯公式文档和已经完成的十一段小型交付，整合成总包。历史来源成员字节保持，原 ZIP 不改。只含图片、视频、结果数据和推导/指导文档，无代码、科学 H5 或可执行程序。提取时验证根目录、扩展名、路径、CRC、旧包内部校验清单，记录每个源成员到新成员的 SHA 对应；生成素材映射与新的主导航。
