# 真空传播、自由漂移与空间电荷阶段性结论

更新日期：2026-10-30。第1–2节对应源码版本 `c7fcd20`；第3节记录加入参考面电流与入口电荷匹配后的当前版本，分别注明比较口径。账本比较在 **boost 系**，以百分数显示；粒子过面能量另按 **lab 系** 或束团初始平均静止惯性系 **rest 系** 标注。

本文记录已完成测试能够支持的结论及其误差范围。真空传播有已知解析参照，原自由漂移测试核对离散能量收支；新增球形束团对照记录当前空间电荷动力学的表现。

**第3节作为当前版本的阶段性结论保留，供后续仿真对照与优化使用。**其中误差仍然存在，不能把阶段性采用理解为全部物理量已达到统一精度；后续修正应另列版本和结果，保留本次基准。

## 1. 真空脉冲传播：与已知解对照

先在网格上放入已知 E/B 脉冲，不含粒子和电流，然后用现有场推进方法演化。脉冲沿 +z 以光速传播，窗口每步向 −z 移动一格，因此脉冲相对窗口每步应平移两格。

这一对照具有明确的参照：在每一步比较数值场与已知平移后的场形，同时将纵向离散面交换与原生端点 E/B 通量公式比较。场能变化还与新账本中的各通道核对。

| 设置 | 本次值 |
|---|---|
| 网格 | $160\times160\times64$ |
| 网格间距 | dx=dy=5 µm，dz≈1.254326 µm |
| 时间步长 | c·dt=dz |
| 核对孔径 | 横向中央 $16\times16$ 单元 |
| 传播步数 | 28 |
| 运行配置 | 单节点 1／4 MPI；双节点 4 MPI |

![真空脉冲：已知场平移、纵向面交换和能量收支核对](figures/01_vacuum_pulse.png)

三个面板分别为场值平移相对偏差、纵向原生面交换核对偏差、归一化场算子账本核对差。各面板采用各自的纵轴尺度。[PDF](figures/01_vacuum_pulse.pdf)

三种配置的最大场平移相对偏差均约为 **$2.2\times10^{-13}$**，端点通量核对偏差约为 **$2.0$–$2.9\times10^{-17}$**。这些结果支持该工况下的已知真空传播及移动窗能量交换与参照相符。该工况覆盖的是纵向一维脉冲在三维网格上的传播。

## 2. 含粒子自由漂移：能量收支的辅助核对

### 束团和场设置

使用 **31,675 个宏粒子**，开启自场反馈，不设置外部磁元件或入射波。束团来自固定种子 `281028` 的合成高斯型输入，包含截断、位置—动量相关和两个尾部见证粒子；横向相关系数约为 −0.7334、−0.6546。

| 设置 | 本次值 |
|---|---|

| boost γ | 929.1305492858543 |
| 活动场窗 | 160 × 160 × 289 |
| 活动窗 lower／upper 保护格 | 64／128 |

| 运行步数 | 257 |

本工况核对粒子能量变化、自洽场能变化、电流与场的交换以及供场／移窗带来的能量变化。时间离散和 Cowan 算子贡献单独记录为数值通道，避免将它们解释为真实辐射或外场做功。

## 3. 当前准稳态入窗方案：物理对照与已知误差

### 对照范围与参考系

当前方案保留快速准稳态参考场，启用横向参考面电流和新层入口电荷匹配，维持可信输入面上的粒子到达事件、位置、动量及权重，不依靠长时间全空间PIC预演化来生成初场。内部 Cowan 场推进、Boris 粒子推进、电流沉积和横向 CPML 方法保持。

这里的当前程序为 `build/charge-matched-inlet-20261030/aprl`，对应物理核心 `81f5f0b8e7fb4b174017c617fd3c6e26a59059ee`；程序 SHA256 为 `79d643bc8ade4db4d9e4488a367cb1bf5ef74e7c602dc3a2094462709aed9435`。以下全部来自已完成的小工况，不使用正在运行的4.5 m／0.5 m大仿真作为证据。

物理基准使用32768个带权宏粒子、无外磁场的球形束团，与独立相对论球壳世界线解对照。主能量量为逐粒子自身入口至指定出口的动能差 $\Delta K_i=K_{i,\mathrm{out}}-K_{i,\mathrm{in}}$，正值表示增能；偏差统一为 **PIC−理论**。`rest` 指束团初始平均静止惯性系，**不是程序的boost系**。

原电荷的−620 eV与上一表的−1048 eV来自理论取样事件不同，不能混用分母或解释成新增改进。最弱两档中，电荷降10倍，末面绝对偏差降8.73倍，局部近似为 $Q^{0.941}$，理论平均增能近似为 $Q^{1.999}$。因此，本次范围内没有固定keV量级的偏差底，**绝对误差减小也不意味着净平均能量变化的相对误差恒定**。四档之间存在偏差符号变化，不能拟合成普适的一条误差律。

最弱档在五个下游面的偏差约为+0.1640、+0.1956、+0.1702、+0.1639、+0.1806 eV，说明主要偏移在较早阶段已经形成，随后保留并调整；这还没有唯一定位激发源。独立70位精度能量重算与原结果的最大差约为 $1.58\times10^{-12}$ eV，远小于此处余差。[完整分析](physical_benchmarks/space_charge_scaling_20261030/RESULT_REVIEW.md) · [逐面数据](physical_benchmarks/space_charge_scaling_20261030/review/all_planes.csv) · [汇总CSV](physical_benchmarks/space_charge_scaling_20261030/analysis_final/summary.csv)。

### 当前保留的能散与收支余差

下表的能散均为**逐粒子ΔK的标准差**，不是出口总动能分布的标准差。lab列仍使用理论自己的同面事件，rest列沿用实际PIC事件时刻口径。

| Q/Q₀ | lab std(ΔK)相对偏差 | rest std(ΔK)相对偏差 | 逐粒子lab ΔK误差RMS／理论std | boost账本最大总差额／D |
|---:|---:|---:|---:|---:|
| 1 | −0.967% | +9.584% | 7.55% | 0.12964% |
| 0.1 | −0.830% | +10.977% | 8.14% | 0.53298% |
| 0.01 | −0.802% | +11.637% | 8.35% | 0.91743% |
| 0.001 | −0.800% | +11.698% | 8.36% | 0.98363% |

冷均匀球rest能散约10%–12%的偏差没有因减弱电荷而消失。最弱档理论lab std(ΔK)约8539 eV，净平均仅0.2904 eV，均值来自较大的正负粒子能量变化抵消；62%的净均值偏差不能直接解释成每个粒子受力都偏差62%，也不能忽略。

账本各组仍用第2节定义的完整记录固定分母 $D=\max|\Delta K_{\mathrm{boost}}|$。场算子累计核对差处于舍入量级，总账本仍有粒子—网格交换余项；最弱档终态差额约 $8.11\times10^{-18}$ J，约为终态净粒子动能变化的180%。因此，表中峰值归一化差额低于1%，并不能证明微小净能量变化已经准确。boost账本差额也不能直接当作lab面能量偏差相减。

### 阶段性采用与后续优化范围

当前先保留这版准稳态注入与推进方案，作为大仿真对照的工作版本，并将上面的均值、能散及收支余差作为已知限制。下一步优化仍需降低初始／入窗瞬态与后续反馈的偏差，检查能散及净平均能量变化的收敛。

以上误差量级仅适用于已测球形束团和对应网格。固定球形几何下缩放总电荷，不能替代真实长束团的纵横比扫描，也没有给更小的辐射能损或近场分离建立误差上界。后续新结果应与本节同口径对照，再更新阶段性结论。

## 4. 可由现有结果支持的结论

| 对照 | 支持的结论 |
|---|---|
| 已知真空脉冲 | 该工况的传播场形、传播位移和纵向面交换与已知参照相符 |
| 含粒子自由漂移 | 该工况的场与粒子离散能量收支可核对，单／双节点结果相符 |
| 当前准稳态入窗的三类球形束团 | 保留主要空间电荷膨胀、聚焦与回弹行为；本组横向RMS尺寸相对偏差约0.03%–0.05%，均值和能散误差另列 |
| 固定球形几何的电荷缩放 | 绝对均值偏差随弱电荷下降，但净均值相对偏差不恒定；rest能散和粒子—网格余差仍需优化 |

各结论按对应版本、参考系、过面事件和归一化分母使用；本记录保留当前已知误差，作为下一轮优化的比较基准。
