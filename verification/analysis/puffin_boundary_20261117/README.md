# Puffin 边界说明交付模板

本模板只评价冻结 Puffin 库中的掩膜函数，并按冻结源码公式计算规定复场的一次边界操作；没有粒子、沿程演化或生产程序修改。

`mask_values.f90` 链接现有 libpuffin_mpi.a，仅调用 getMask 和 getZ2Mask。`prepare.py` 保存来源身份、编译小型数值读取器并导出公式数据。`render.py` 导出中英文科学图和规定输入位置扫描视频；视频横轴为输入中心位置，绝不是 Puffin 沿程传播。`deliver.py` 生成说明、PPT任务指令和独立ZIP。

生产六段/十一段的边界污染程度、反射率和修复收益不在这些单次算子计算中得到测量。发现的纵向长度表达式问题必须与这一限制一起转交。不得把 APRL 的 CPML 反射数值移植给 Puffin。
