# 已闭合 Puffin 实际传播交付

只处理19834闭合结果，不运行新物理仿真、不修改冻结脚本、源库或原始输出。新版主图视频来自真实原生推进，不使用规定输入位置扫描。

prepare.py保护来源身份、复用原数组和统计，并用独立的周期像高斯解析叠加验证关闭吸收时的绕回。render.py修正原绘图的字面TeX刻度和像素坐标，生成固定线性/对数两种视频、空间传播图和中央弱返回放大图。write_docs.py给出直观图解与PPT制作指令。finish.py验证来源、数据和包内链接后打包，人工目视记录必须存在才更新独立Puffin交付索引。

旧说明包及旧总PPT包保持；纵向mask表达式问题留在源码附件，与本轮仅测试横向边界的范围分开。内部反馈指辐射场偏离大域参考，没有粒子/FEL反馈。

用户后续要求只展示原生吸收与大域参考。select_native.py从已验收r2中直接选择相关CSV行、NPZ数组和元数据，生成带SELECTION.json的新交付目录；renderer自动导出双栏视频与10组单图，write_docs调用docs_native.py给出相应讲稿。finish验证保留的原值与旧包一致，并检查选出的文档/统计中没有被移除场景的内容。原始测试与旧ZIP不改。
