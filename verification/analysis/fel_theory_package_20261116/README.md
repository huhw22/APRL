# FEL 图文交付与理论资格整理

`build.py WORKSPACE OUTPUT ZIP` 仅读取已经闭合的小型图文/CSV/JSON 和旧转交 ZIP 的校验；不读取科学 H5，不演化场/粒子。新建交付目录，复制最新双方法能量曲线、当前三方法增长结果、空间电荷完整推导、旧独立随机首段证据，并隔离修复前相关加载的历史谢明比较。

谢明七项拟合按原文实现三种明确圆束化，记录每项修正；只将结果视为局部参考。所有相邻出口斜率保留，以名义磁长而非物理间隙距离计算。BF 入口/出口比例从已验 CSV 重算；不把三点核 5.17% 理论值与五次补偿 5.16% 实测值当配对验证。

使用 physics 环境，指定可写 MPLCONFIGDIR 和单线程 BLAS。每张新图独立单轴，PNG/PDF 中英文双版，无数学上下标/角标。人工查看图后执行 `finalize.py OUTPUT ZIP`，核对源 SHA、配方的独立等价表达、CSV/绘图数组、Markdown 相对链接和 ZIP CRC/成员 SHA。只归档图与结果/推导记录，无代码或原始大输出。原交付 ZIP 保持原字节。`MING_XIE.md` 与 `BF_SPACE_CHARGE.md` 是输出文档模板。
